# 지도

catalog.json은 표시 이름과 실제 지도 파일을 연결합니다. 각 폴더의 map.json이 현재 실행 원본입니다.

- chapter-1: 황건소탕. docs/에 제작 지침·캡처, history/에 이전 배치, review/에 검토 화면, archive/에 미사용 건물 시안.
- character-review: 캐릭터 검수 지도.
- character-overview: 캐릭터 전체 검수 지도.
- custom: 맵메이커에서 새 이름으로 저장한 지도.

공유 지형 그림은 art/terrain, 캐릭터는 characters를 참조합니다. [폴더 규칙](../docs/ASSET_LAYOUT.md).
