2026-10-28 검토본. 실제 작업 맵은 maps/chapter-1/map.json.

- 남쪽 마을: 민가, 주막, 대장간, 무기고, 보급 수레.
- 서쪽/동쪽 구출 야영지: 황건 야영막, 병영, 감옥, 무기 거치대.
- 강 북쪽 관해 진지: 병영, 초소, 보급 수레.
- 산길: 통행 가능한 산채 문.
- 북쪽 장각 진지: 병영, 야영막, 초소, 제단.
- 기존 풀밭·길·흙마당·강·산·나무·울타리 등 공통 지형은 재사용한다.

기존 72×72 배치, 지형 좌표, 진행 순서, NPC/건물 정의, 유닛33개, 자원 나무80개를 보존했다. 원본 배치는 layout-before-art.map.json. 원본을 복원할 때는 작업 맵에 덮어쓰므로 현재 편집본부터 백업한다.

맵메이커의 삼국 팔레트는 새 그림12종 + 자동 연결 지형2종이다. 편집 화면의 안개 체크는 표시만 바꾸며 실행 시 진행 안개는 유지한다.

검증: tools/map-art/verify_chapter1.mjs — 시나리오 원본 비교, 원래 통행 가능한 유닛/NPC 위치 유지, 시작·마을·구출2곳·다리·관해·산길·내부진지·장각까지 9개 지점의 실제 격자 연결 검사. GridNav.path의 실패 시 직선 fallback을 쓰지 않고 flood fill로 검증한다.

공용 자산 상세는 maps/chapter-1/archive/building-drafts/README.md. 이동·공격 자산은 이번 작업에서 수정하지 않았다. 신규 건물의 상호작용 기능은 별도 개발 대상이다.
