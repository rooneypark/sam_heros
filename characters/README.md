# 캐릭터 리소스

각 영문 이름 폴더에 원화·초상화·모션·생성 근거·보관 자료를 모았습니다. [전체 미리보기](index.html), [폴더 규칙](../docs/ASSET_LAYOUT.md), [실행 등록](../content/samguk/units.json)을 참고합니다.

현재 활성 15종은 units.json 기준입니다. village-woman 등 등록되지 않은 기존 승인 자료도 보존하며 임의로 다시 활성화하지 않습니다. 기존 승인/검토 상태는 이번 폴더 정리로 변경되지 않습니다.

새 모션은 해당 캐릭터 폴더 안에 추가하고 날짜별 최상위 폴더를 만들지 않습니다. 전체 활성 프레임 체크섬은 manifest.json입니다.
