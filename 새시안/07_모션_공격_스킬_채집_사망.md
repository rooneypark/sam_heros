# 07. 공격·스킬·채집·사망 (원작 측정)

참고: [영웅 공격·스킬·채집·사망 시트](참고/원작모션/02_영웅_공격_스킬_채집_사망.png) — 빨간 테두리가 **타격 프레임**(게임이 피해를 주는 순간). GIF `Hero_09_Attack.gif`, `Hero_06_Attack.gif`, `Hero_09_Skill_01.gif`, `Hero_42_Gather.gif`.

## 1. 기본 공격 (`basic-attack/`)

| 항목 | 원작 측정 (영웅 86명) | 제작 기준 |
|---|---|---|
| 프레임 수 | 7~11장 (8장이 가장 많음) | **8~9장** |
| 프레임당 시간 | 67~83ms (같은 길이 유지가 많음) | 67~83ms |
| 전체 길이 | 중앙값 0.85초 (0.52~1.0초가 대부분) | 0.6~0.9초 |
| 타격 시점 | 중앙값 0.5초. Hero_09: 9장 중 5번째(0.33초) | 전체의 40~55% 지점 |

**원작 공격의 리듬** (Hero_09 9장 × 67ms 예):

| 단계 | 프레임 | 그림 |
|---|---|---|
| 준비 (모으기) | 1~3 | 무기를 뒤로·위로 들어 올리며 몸을 웅크림. 거의 같은 자세를 2~3장 유지해 **멈칫** |
| 휘두름 | 4 | 몸을 크게 앞으로 내던짐. **무기 궤적(흰 반달 잔상)을 그림 안에 직접 그림** |
| 타격 | 5 | 가장 낮고 길게 뻗은 자세. 무기가 진행 방향 끝 |
| 여운 | 6~8 | 뻗은 자세를 거의 그대로 2~3장 유지 (같은 그림 반복 가능) |
| 복귀 | 9 | 기본자세 쪽으로 |

- 손맛은 **준비의 멈칫 → 한 프레임에 확 뻗기 → 여운 유지**에서 나온다. 준비와 타격 사이에 중간 프레임을 많이 넣으면 느려 보인다
- 휘두르는 프레임의 잔상은 몸 그림의 일부다. 터지는 스파크는 이펙트로 따로 그린다([08장](08_이펙트.md))
- 찌르기(Hero_06 창, 12장): 준비 1장 → 창을 앞으로 내밀고 3~4장 유지 → 타격 → 창을 세워 돌아옴 4~5장
- 관우 잔상은 첫 베기 한 번만. 복귀 중 다시 생기지 않게

## 2. 스킬 (`skill-1/`, `skill-2/`)

| 항목 | 원작 측정 | 제작 기준 |
|---|---|---|
| 프레임 수 | 스킬1 8~12장, 스킬2 9~13장 | **9~12장** |
| 전체 길이 | 스킬1 중앙값 1.18초, 스킬2 1.43초 | 1.0~1.4초 |
| 타격 시점 | 스킬1 0.67초, 스킬2 0.78초 | 전체의 55~65% |

**원작 스킬의 리듬** (Hero_09 스킬1 대지진 13장 × 83ms):

| 단계 | 프레임 | 그림 |
|---|---|---|
| 기 모으기 | 1~5 | 기본 공격보다 길게, 무기를 세우고 몸을 낮춤 |
| 도약 | 6~8 | **몸 전체가 공중으로** — 무기를 머리 위로 크게 |
| 강타 | 9 | **번진(모션 블러) 그림 한 장** — 몸과 무기가 흐릿하게 내려꽂힘 |
| 충격 | 10~11 | 땅을 찍은 자세 + 흙덩이·파편이 그림 안에서 튐 |
| 복귀 | 12~13 | 무기를 들고 일어남 |

- 스킬은 기본 공격보다 **크게**: 도약·회전·큰 휘두르기. 실루엣이 한눈에 다르게
- 치유·버프 스킬(유비, 관우 스킬2, 장비 스킬2)은 타격 대신 **시전 포즈**가 절정이다. 그 프레임에 이펙트가 터진다(08장)

## 3. 채집 (`gather/`)

원작 영웅 **86명 전원이 같은 규격**이다.

| 항목 | 값 |
|---|---|
| 프레임 | **9장 × 83ms = 0.77초**, 반복 |
| 타격(나무·바위를 치는 순간) | **0.5초 = 7번째 프레임** |

| 프레임 | Hero_42 예 |
|---|---|
| 1~3 | 도구(무기)를 쥔 팔을 뒤로 들어 올림 |
| 4~5 | 크게 휘두르며 몸을 비틂 |
| 6 | 잠깐 멈춤 |
| 7 | **허리를 숙여 내리침** (타격) |
| 8~9 | 일어나며 기본자세로 |

자기 무기로 나무·바위를 친다(별도 도끼·곡괭이 없이). 7번째 프레임에 맞춰 나무가 번쩍이고 흔들린다(게임 자동).

## 4. 사망 (`die/`)

| 대상 | 원작 | 제작 기준 |
|---|---|---|
| 영웅 (장수) | **86명 전원 정지 1장** | 1장: 앞으로 엎드려 쓰러진 자세, 얼굴 안 보임, 무기는 옆에 |
| 몬스터 | 4장 × 100ms가 가장 많음 | 4장: 움찔 → 젖혀짐 → 넘어감 → 누움 ([03장](03_몬스터.md) 3절) |
| 보스 | 5~6장 | 무기 떨어뜨림 → 무릎 → 쓰러짐 |

사망 그림도 발 기준 (175,245) 캔버스 안에서 누운 몸의 중심이 발 위치 근처에 오게 한다.

## 5. 공통 규칙

- 모든 프레임 350×350, 발 (175,245). 점프·도약 프레임은 발이 위로 올라간 그대로
- 머리·몸·무기 크기와 굵기는 고정 (회전·기울임·잔상은 가능)
- 프레임마다 처음부터 새로 생성하면 얼굴·옷이 달라진다. **원화를 기준으로 자세만 바꿔** 그리고, 원화와 나란히 비교
- 타격 프레임 번호를 `animation.json`에 적는다(09장). 개발이 그 시간에 피해·이펙트·소리를 맞춘다
