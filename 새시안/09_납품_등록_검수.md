# 09. 납품·등록·검수

## 1. 작업 위치 — 승인 전에는 `새시안/작업/`

기존 실행 그림(`characters/`, `art/terrain/`)을 바로 덮어쓰지 않는다. 새 그림은 아래에 같은 구조로 만든다.

```
새시안/작업/
  characters/<영문이름>/original/original.png
                       /idle/frame-01.png … frame-04.png, animation.json
                       /run/frame-01.png … frame-06.png, animation.json
                       /basic-attack/ skill-1/ skill-2/ gather/ die/ work/ portrait/
  terrain/<이름>/<이름>.png
  fx/<이름>/frame-01.png …, README.md
```

캐릭터 영문 이름: `liu-bei` 유비, `guan-yu` 관우, `zhang-fei` 장비, `zhao-yun` 조운, `yellow-turban-soldier` 졸병, `yellow-turban-spearman` 창병, `yellow-turban-archer` 궁병, `yellow-turban-wolf` 늑대, `guan-hai` 관해, `zhang-jiao` 장각, `village-hostess` 주모, `village-elder` 노인, `village-boy` 소년, `village-blacksmith` 대장장이, `armory-guard` 경비병.

**승인되면** 개발이 기존 폴더를 `archive/`로 옮기고 새 그림을 같은 경로에 넣는다. 등록 파일(`content/samguk/units.json`, `tiles.json`)의 경로가 그대로라 맵·진행 데이터는 바뀌지 않는다.

## 2. 파일 규격

| 대상 | 규격 |
|---|---|
| 캐릭터 프레임 | 350×350 투명 PNG, 발 (175,245), 왼쪽 시선, `frame-01.png`부터 빠짐없이 |
| 원화 | 같은 규격 1장. 큰 원본은 `sources/`에 따로 보관 |
| 지형·소품 | 투명 PNG, 바닥 중심 pivot (0.5, 0.18) |
| 바닥 재질 | 724×724 이음매 없는 PNG |
| 이펙트 | 256×256, 중앙 pivot |
| 파일 이름 | 영문 소문자·숫자·하이픈. 한글·공백 금지 |

## 3. `animation.json` (모션 폴더마다)

```json
{
  "frames": ["frame-01.png", "frame-02.png", "frame-03.png", "frame-04.png", "frame-05.png", "frame-06.png"],
  "durations": [83, 83, 83, 83, 83, 83],
  "loop": true,
  "hitFrames": []
}
```

- `durations`: 프레임별 ms. 같은 그림을 반복하려면 `frames`에 같은 이름을 다시 적는다 (숨쉬기 1-2-3-2)
- `hitFrames`: 공격·스킬·채집의 타격 프레임 번호 (1부터). 예: 채집 `[7]`
- `loop`: 숨쉬기·이동·채집·오라 true, 공격·스킬·사망 false

## 4. 검수 순서

1. **원화 한 장** — [유비 기준 시안](참고/기준/유비_새시안_기준.png)과 나란히. 선 5~6px, 머리 비율, 채도 ([01장](01_공통_화풍.md))
2. **게임 크기로 축소** — 60~70px 높이에서 누구인지 읽히는지
3. **모션 GIF** — [원작 GIF](참고/원작모션/)와 나란히 재생해 박자 비교 ([06장](06_모션_숨쉬기_이동.md), [07장](07_모션_공격_스킬_채집_사망.md))
4. **모션체커** — `run_motion_checker.bat` (개발이 작업 폴더를 연결해 준다)
5. **게임 화면** — `run_samguk.bat`에서 마을·숲 배경 위에 서고, 달리고, 싸우는 모습
6. **수치 재측정** — 개발에게 폴더를 알려 주면 키·머리 폭·선 굵기·채도·밝기·점프 높이를 같은 방법으로 재고 이 문서와 대조한다

## 5. 개발에게 넘길 때

폴더 경로와 아래만 알려 주면 된다.

- 어떤 캐릭터·모션인지, 프레임 수, 타격 프레임
- 승인 여부 (검토본인지 확정인지)
- 이펙트는 가장 크게 터지는 프레임

등록(`units.json`, `tiles.json`), 게임 내 타이밍, 이펙트 재생, 그림자, 흰 번쩍임, 사망 후 페이드는 개발이 한다. 디자이너가 JSON을 직접 고칠 필요는 없다.

## 6. 하지 않을 것

- 승인 전에 기존 `characters/`, `art/terrain/` 파일 덮어쓰기
- 프레임마다 크기 자동 맞춤, 몸 늘이기·줄이기, 모핑
- 프레임별로 여백을 잘라 캔버스 크기 바꾸기
- 원작 그림을 그대로 베껴 넣기 — 원작은 **동작·박자·비율의 참고**이고 외형은 삼국 캐릭터로 새로 그린다
