# 05. 맵 — 바닥·길·물·산·건물·소품·채집 자원

공통 화풍 [01장](01_공통_화풍.md). 맵 그림의 목표는 하나다: **캐릭터가 배경보다 먼저 보일 것.**

## 1. 화면 구조 (원작 측정)

| 항목 | 값 |
|---|---|
| 지형 칸 | 화면에서 400×240px 마름모 (아이소메트릭) |
| 장식 칸 | 지형 칸의 1/3 (133×80px 마름모). 건물·소품은 여기에 놓인다 |
| 카메라 | 화면 세로 26칸(월드 단위). 캐릭터 키 약 1.35칸 = 지형 칸 하나보다 작다 |
| 소품 PPU | 100 (캐릭터와 같음 → 100px = 1칸). 산은 120 |
| 그리는 순서 | 바닥 → 길 → 물 → 장식(화면 아래쪽이 앞) → 산·절벽 |

## 2. 원작 대비 이전 그림의 문제 (측정)

| 대상 | 원작 | 이전 삼국 | 고칠 방향 |
|---|---|---|---|
| 소품 선 | 얇거나 색선 | 순검정·굵음 (높이의 3.6~5.8%) | 캐릭터보다 얇게(1.5~2%), **물체 색의 짙은 선** |
| 감옥·울타리·망루 | — | 밝기 17~26, 검은 덩어리 | 밝기 30 이상, 밝은 갈색 목재, 그림자 면적 축소 |
| 채집 나무 | 밝기 61, 채도 93 (밝은 연두) | 밝기 48, 채도 42, 장식 나무와 같은 그림 | 밝고 진하게, **장식 나무와 다른 그림** |
| 광석 | 하늘색 결정이 빛남 | 어두운 청회 바위 | 빛나는 결정·광맥 |
| 초원 바닥 | 밝기 49, 채도 71 | 밝기 50, 채도 62 | 거의 맞음 |
| 흙 | 밝기 58, 채도 35 | 밝기 65, 채도 45 | 조금 어둡고 덜 진하게 |
| 물 | 밝기 38, 채도 78 | 밝기 49, 채도 64 | 조금 더 진하게 |

## 3. 바닥·길·물 — 재질 그림 (`type: material`)

지금 게임은 칸마다 조각을 잇는 방식이 아니라 **이음매 없는 재질 그림 한 장**을 엔진이 모양대로 잘라 깐다.

| ID | 이름 | 파일 | 규격 |
|---|---|---|---|
| sg2_ground | 초원 | `art/terrain/grass-material/grass-material.png` | 724×724, **사방 이음매 없음(타일링)** |
| sg2_road / sg2_yard | 흙길 / 흙마당 | `art/terrain/earth-material/earth-material.png` | 같음 |
| sg2_river | 강·연못 | `art/terrain/water-material/water-material.png` | 같음 |

- 무늬는 작고 고르게. 큰 얼룩·뚜렷한 돌·풀포기는 반복이 티 나므로 장식(`sg2_grass`, `sg2_flowers`)으로 따로 놓는다
- 경계(물가·길가) 색은 `tiles.json`의 `shore` 값으로 엔진이 그린다 (흙 `#b69871`, 물가 `#75c2d5`). 색을 바꾸려면 값만 알려 주면 된다
- 원작처럼 **바닥은 선 없이 색면**만. 바닥이 캐릭터보다 밝거나 진하면 캐릭터가 묻힌다

## 4. 산·절벽 (`blockData`)

`sg2_mountain` 400×268, PPU 120, pivot (0.5, 0.18). 지나갈 수 없는 맵 가장자리 벽 역할. 위로 솟은 부분은 칸 밖으로 넘쳐도 된다. 어둡게 뭉치지 않게 위쪽 면을 밝게.

## 5. 건물·소품 (`decoData`, `type: single`)

| 항목 | 규칙 |
|---|---|
| 형식 | 투명 PNG 한 장 |
| 기준점 | **땅에 닿는 바닥 중심.** pivot `[0.5, 아래에서 비율]`, 지금 대부분 `[0.5, 0.18]` |
| 크기 | 캐릭터(키 135px)에 맞춤. 민가 문 높이 ≈ 캐릭터 키. 지금 크기: 주막 300×284, 민가 275×248, 나무 190×196, 목책 145×99, 술독 55×64 |
| 통행 | 못 지나가는 것은 `blocks: true`, 큰 건물은 `footprint: [3,3]` (장식 칸 단위) |
| 방향 짝 | 울타리·벽·문처럼 이어지는 것은 **두 방향을 따로** 그린다(`fence_a` ↗, `fence_b` ↘). 단순 좌우 반전이면 그림자 방향이 바뀌니 다시 맞춘다 |
| 그림자 | 바닥 그림자를 그림 안에 짧게 포함 |
| 앞뒤 가림 | 화면 아래 것이 위 것을 가린다. 큰 지붕은 위로 높게 그려도 된다 |

**지금 등록된 46종** (`content/samguk/tiles.json`, 파일은 `art/terrain/<이름>/<이름>.png`) — 같은 파일 이름으로 바꾸면 맵 배치는 그대로 유지된다.

| 구분 | 목록 |
|---|---|
| 자연 | tree 나무, oak 짙은 나무, dead_tree 마른 나무, bush 수풀, thorn 가시 덤불, reeds 갈대, grass 풀잎, flowers 들꽃, boulder 이끼 바위, stones 작은 돌, stump 그루터기 |
| 마을 건물 | tavern 주막, cottage 민가, blacksmith 대장간, armory 무기고, well 우물, farm 채소밭, market 장터, meal_table 주막 평상, fishing 강가 어구, woodshop 벌목 작업대, shrine 사당 |
| 황건 진영 | barracks 병영, tent 야영막, watchtower 초소, cage 감옥, banner 황건 깃발, altar 제단, supply 보급대, rack 무기 거치대 |
| 소품 | fence_a/b 목책, torch 화로, fire 모닥불, jar 술독, barrel 나무통, sacks 곡식 포대, cart 수레, sign 이정표, planks 부서진 판자, logs 장작 |

**원칙:** 건물·소품은 캐릭터보다 **채도 한 단계 낮고, 선이 얇다.** 대신 형태는 단순하고 큼직하게.

## 6. 채집 자원 (새로 필요)

지금 채집 나무·광석은 장식 나무·바위와 **같은 그림**이라 캘 수 있는 것이 구분되지 않는다.

| 새 파일 | 내용 | 크기 |
|---|---|---|
| `art/terrain/resource-tree/resource-tree.png` | 채집 나무 — 밝은 연두 잎, 열매나 도끼 자국. 장식 나무보다 밝고 진하게(밝기 55~60, 채도 70+) | 190×196 안팎 |
| `art/terrain/resource-tree/resource-stump.png` | 벤 뒤 그루터기 | 70×50 안팎 |
| `art/terrain/resource-ore/resource-ore.png` | 광석 바위 — **빛나는 결정·광맥** | 200×150 안팎 |
| `art/terrain/resource-ore/resource-rubble.png` | 다 캔 돌무더기 | 70×45 안팎 |

pivot (0.5, 0.18), 멀쩡한 그림과 남은 그림의 **바닥 위치를 같게**. 맞을 때 흰 번쩍임·흔들림·아이콘 튀기기는 게임이 자동으로 붙인다.

## 7. 움직이는 소품 (선택)

모닥불 불꽃, 깃발 펄럭임, 화로, 연기는 4프레임 반복으로 그려 주면 개발이 움직이는 부품으로 등록한다. 폴더 `art/terrain/<이름>/frame-01.png…`, 프레임당 100~150ms.

## 8. 맵 체크리스트

- [ ] 맵메이커(`run_maker.bat`)에 깔고 장수·적을 세워 **캐릭터가 먼저 보이는지**
- [ ] 소품 선이 캐릭터보다 얇고 물체 색
- [ ] 어두운 덩어리(밝기 25 이하 큰 면) 없음
- [ ] 채집 나무·광석이 장식과 확실히 다름
- [ ] 울타리 두 방향 이음새 자연스러움
