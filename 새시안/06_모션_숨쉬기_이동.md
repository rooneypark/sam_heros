# 06. 숨쉬기·이동 — 통통 튀는 느낌 (원작 측정)

원작 《우르르 용병단》 영웅 86명의 실제 애니메이션 데이터(프레임 순서·시간)와 프레임 그림을 같은 350 캔버스에 놓고 잰 값이다. 장수·몬스터·NPC 모두 이 규칙을 쓴다.

참고: [영웅 숨쉬기·이동 시트](참고/원작모션/01_영웅_숨쉬기_이동.png) (빨간 선 = 발 y245), 실제 속도 GIF `참고/원작모션/Hero_42_Idle.gif`, `Hero_09_Move.gif` 등.

## 0. 왜 이전 모션은 밋밋했나

| | 원작 | 이전 삼국 장수 |
|---|---|---|
| 숨쉬기 속도 | 프레임당 **83~100ms**, 한 주기 0.33~0.43초 | 프레임당 300ms, 한 주기 1.2초 |
| 숨쉬기 방향 | 머리가 **아래로** 3px 눌림 (발 고정) | 상체가 위로 4px |
| 이동 속도 | 프레임당 **83ms**, 6장 = 0.5초 | 100ms, 0.6초 |
| 이동 시 발 | **몸 전체가 땅에서 떠오름** (최고 23px = 키의 17%) | 발은 땅에 붙고 상체만 3~7px 위아래 |
| 착지 | 꼭대기에서 **한 프레임 만에 바로 착지** | 부드럽게 내려옴 |

원작의 통통 튀는 느낌은 **빠른 박자 + 몸 전체 점프 + 뚝 떨어지는 착지**에서 나온다. 다리를 정교하게 움직이는 것보다 이 세 가지가 훨씬 중요하다.

## 1. 숨쉬기 (`idle/`) — 4장

| 항목 | 원작 측정 | 제작 기준 |
|---|---|---|
| 프레임 수 | 4장 70%, 3장 27% | **4장** |
| 순서 | 1-2-3-4 또는 1-2-3-2 (핑퐁) | 3장만 그리고 1-2-3-2로 재생해도 됨 |
| 프레임당 시간 | 83ms (55%), 100ms (일부 여성·마법 영웅 등) | **83ms** (차분한 캐릭터 100ms) |
| 한 주기 | 0.33~0.43초 | 약 0.35초 |
| 움직임 | 머리끝이 0 → 2 → 3 → 2px **아래로**. 발과 무기 끝은 고정 | 아래 표 |

| 프레임 | 머리·상체 | 하체·발 | 설명 |
|---|---|---|---|
| 1 | 0px (원화 그대로) | 고정 | 서 있는 자세 |
| 2 | 아래로 2px | 고정 | 살짝 웅크림 |
| 3 | 아래로 3~4px, 어깨·소매가 1~2px 옆으로 퍼짐 | 고정 | 가장 눌린 자세 |
| 4 | 아래로 2px | 고정 | 돌아오는 중 (= 2번 재사용 가능) |

- 위로 들어 올리지 말고 **아래로 눌렀다 펴는** 느낌. 원작은 무릎을 굽히는 듯이 몸이 내려간다
- 머리·관·머리카락 끝은 0.5~1프레임 늦게 따라가면(2번에서 1px, 3번에서 3px) 말랑하다
- 크기 고정 규칙은 그대로: 눌릴 때 **위치만 내리고** 머리·몸을 찌그러뜨리지 않는다. 옷자락만 살짝 퍼지는 정도
- 관우·장비처럼 무기 끝을 땅에 짚으면 무기와 쥔 손은 고정

## 2. 이동 (`run/`) — 6장, 두 번 뛴다

| 항목 | 원작 측정 (6장 영웅 63명) | 제작 기준 |
|---|---|---|
| 프레임 수 | 6장 73% | **6장** |
| 프레임당 시간 | 83ms | **83ms** → 한 주기 0.5초, 끝에 1번을 덧붙이지 않음 |
| 한 주기 점프 | **2번** (1-2-3, 4-5-6) | 한 걸음 = 한 번 깡총 |
| 뜨는 높이 (발 바닥 기준) | 1: 0 / 2: **15px** / 3: **23px** / 4: 0 / 5: 15 / 6: 23 (가운데 50%: 2번 7~18, 3번 16~28) | 아래 표 |
| 최고 높이 / 키 | 약 17% | 키 135px이면 **20~25px** |

| 프레임 | 발 높이 | 자세 |
|---|---|---|
| 1 | **0** (발 y=245 접지) | 착지. 무릎 굽혀 살짝 웅크림, 몸이 진행 방향으로 기울어짐 |
| 2 | **위로 15px** | 박차고 떠오름. 뒷발이 뒤로 차고, 앞발은 앞으로 |
| 3 | **위로 23px** (최고점) | 공중. 두 다리를 몸 아래로 **모아 접음**. 무기·머리카락·옷자락이 아래로 처짐 |
| 4 | **0** | 반대 발로 착지 (꼭대기에서 바로 착지 — 내려오는 중간 프레임 없음) |
| 5 | 15px | 반대 발로 박참 |
| 6 | 23px | 공중, 다리 모음 |

- **몸 전체(발 포함)를 위로 옮긴다.** 그림자는 게임이 바닥에 따로 그리므로 그림에 넣지 않는다
- 상체는 진행 방향(왼쪽 아래)으로 5~10° 기울인다. 머리가 발보다 앞에 있다
- 1↔4, 2↔5, 3↔6은 좌우 다리 역할만 바꾼다. 몸 전체를 좌우 반전하지 않는다
- 다리 길이를 늘려 보폭을 만들지 않는다. 짧은 다리를 **굽히고 모으는 각도**로 표현
- 무기·머리카락·옷자락은 몸보다 한 프레임 늦게: 3번(최고점)에서 아래로 처지고, 1번(착지)에서 위로 살짝 튄다
- 크기·굵기는 프레임마다 같다

## 3. 캐릭터 종류별 조정

| 대상 | 숨쉬기 | 이동 |
|---|---|---|
| 장수 | 83ms, 3px | 83ms, 20~25px |
| 황건 졸병·창병·궁병 | 83ms, 3px | 83ms, 15~22px |
| 주민 | 83~100ms, 2~3px | 83ms, 키의 10% 안팎 |
| 늑대 | 83ms, 2~3px (몸통 위아래) | **67ms × 6장 (0.4초)**, 앞뒤 다리 모았다 뻗기, 최대 25px |
| 보스 (관해·장각) | 100ms, 4px | 100ms, 키의 8~10% (무겁게) |

## 4. 납품·확인

- 각 폴더 `frame-01.png …`, 350×350, 발 (175,245) — 이동 중 뜬 프레임은 발이 위로 올라간 그대로 둔다(캔버스 위치를 다시 맞추지 않는다)
- 같은 폴더에 `animation.json`으로 프레임별 시간(ms)을 적는다 ([09장](09_납품_등록_검수.md))
- 원작 GIF와 **나란히 재생**해서 박자가 같은지 본다. 느리면 밋밋하고, 착지 중간 프레임을 넣으면 둥둥 떠 보인다
- 게임에서 확인: 조이스틱으로 달리다 멈추면 숨쉬기로 바뀐다. 부대가 움직일 때 셋이 각자 깡총깡총 뛰어야 한다
