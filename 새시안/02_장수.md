# 02. 장수 — 유비·관우·장비·조운

공통 화풍은 [01장](01_공통_화풍.md). 기준 그림은 [유비 새 시안](참고/기준/유비_새시안_기준.png)이다.

## 1. 바꾸지 않는 납품 규격

| 항목 | 값 |
|---|---|
| 캔버스 | 350×350 투명 PNG (원작 영웅 스프라이트와 같은 크기) |
| 발 기준점 | **(175, 245)** — 두 발 바닥 중앙. 모든 모션·모든 프레임 동일 |
| pivot / PPU | (0.5, 0.3) / 100 → 100px = 게임 1칸 |
| 방향 | **왼쪽 아래 대각** 시선 (art.facing=left). 오른쪽은 게임이 뒤집는다 |
| 크기 고정 | 머리·몸·다리·무기의 크기·굵기는 프레임마다 바꾸지 않는다 (회전·기울임은 가능) |

원작 영웅도 350×350, pivot (0.5, 0.3)이다(측정). 발 위치가 같으므로 원작 프레임을 옆에 두고 그대로 비교할 수 있다.

## 2. 비율 목표 (350 캔버스, 무기 제외)

| 항목 | 목표 | 유비 새 시안 (측정) |
|---|---|---|
| 몸+머리 키 | 125~140px | 135px로 정리 |
| 머리 높이 (관·상투 포함) | 키의 45~55% | 약 54% |
| 머리 폭 | 80~105px | 약 82px |
| 몸통 폭 (팔 포함) | 85~110px | 약 85~90px |
| 다리 | 키의 20~25%, 짧고 굵게. 좁게 살짝 벌린 자세 | 맞음 |
| 바깥선 | 5~6px | 약 5px |

**줄일 때 주의:** 큰 원본에서 350 캔버스로 줄이면 선이 같이 가늘어진다. 줄인 뒤 선이 5px 아래로 떨어지면 원본 선을 더 굵게 그려서 다시 줄인다. 줄인 결과를 손으로 다시 가늘게 다듬지 않는다.

## 3. 장수별 외형

| 장수 | 실루엣 포인트 (작게 봐도 보여야 함) | 대표색 | 무기 |
|---|---|---|---|
| 유비 | 금관 + 붉은 보석, 상투, 작은 콧수염 | 적·금, 흰 바지 | 길고 곧은 은색 검 + **청록 중앙 무늬**. 두 손으로 한 검을 몸 가까이 쥠. 허리 양쪽 칼집 2개 |
| 관우 | 녹색 두건, **붉은 얼굴**, 길게 늘어진 수염 | 녹·적 | 언월도. **매끈한 날은 항상 바깥(베는 방향)** 을 향한다. 자루는 한 직선 |
| 장비 | 덥수룩한 검은 수염, 부릅뜬 눈 | 회색 복장·붉은 띠·두 겹 밑단 | 장팔사모 (뱀처럼 굽은 창날) |
| 조운 | 흰 갑옷, 푸른 깃 장식 | 백·청 | 창 |

- 기본자세 무기: 유비는 두 손으로 검을 든다. 관우·장비는 **한 손으로 세운 무기 끝을 땅에** 짚는다
- 무기가 얼굴을 가리지 않게 한다. 숨쉬기·이동 프레임에서도 얼굴과 겹치지 않는지 확인한다
- 새 장수를 추가할 때도 같은 표를 채운다

## 5. 장수 스킬 (모션 내용)

기획 확정 내용이다. 수치는 기획 문서를 따르고, 그림은 동작만 맞추면 된다.

| 장수 | 기본 공격 | 스킬1 | 스킬2 |
|---|---|---|---|
| 유비 | 검 찌르기 | 단일 치유 — 두 번째 검을 뽑아 가슴 앞 교차 → 납도 | 전체 치유 — 머리 위 교차 → 납도 |
| 관우 | 베기 (잔상은 첫 베기 한 번만) | 크게 내려 베기 | 공격력 버프 (언월도 들어 기합) |
| 장비 | 창 찌르기 | 크게 한 바퀴 휘두르기 | 포효 — 아군 방어 버프 |
| 조운 | 창 찌르기 | (기획 확정 후) | (기획 확정 후) |

## 6. 원화 체크리스트

- [ ] 350×350 투명, 발 바닥 중앙이 (175,245)
- [ ] 키 125~140px, 머리 45~55%, 바깥선 5~6px
- [ ] 대표색 2~3개, 채도 35~50, 그라데이션 없음
- [ ] 게임 크기로 줄여도 얼굴·관·무기가 읽힘
- [ ] 유비 기준 시안과 나란히 놓았을 때 같은 화풍
- [ ] 무기가 얼굴을 가리지 않음, 실루엣 밖 0.5칸 이내
