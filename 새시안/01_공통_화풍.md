# 01. 공통 화풍 — 모든 그림에 적용

기준 그림: [유비 새 시안](참고/기준/유비_새시안_기준.png). 캐릭터·몬스터·NPC·건물·소품·UI·이펙트가 **같은 게임 그림으로 보이는 것**이 개별 그림의 완성도보다 우선이다.

## 1. 왜 다시 그리나 (원작 측정)

게임 기본 카메라는 화면 세로 26칸을 보여 준다. 캐릭터 키 약 1.35칸은 **화면 높이의 5%** 밖에 안 된다. 원작은 이 크기에서도 누구인지 읽히도록 다음처럼 그렸다.

| 항목 | 원작 영웅 (측정) | 이전 삼국 장수 | 새 유비 시안 |
|---|---|---|---|
| 머리 높이 / 키 | 45~50% (통통한 2등신) | 약 35% | 약 54% |
| 머리 폭 | 1.0칸 안팎 | 0.53~0.80칸 | 약 0.82칸 |
| 바깥 윤곽선 (게임 크기) | 6~8px | 2px | 약 5px |
| 선 색 | 순검정 | 순검정 | 순검정 |
| 명암 단계 | 기본색 + 그림자 1 + 하이라이트 1 | 그라데이션 섞임 | 기본+그림자+하이라이트 |

배경 소품은 원작보다 선이 굵고 어두웠다. 그래서 **배경이 캐릭터보다 진해 보여 장수가 묻혔다**([현재 게임 화면](참고/기준/현재게임화면_마을.jpg)).

## 2. 선

| 대상 | 바깥선 (350 캔버스 기준) | 안쪽선 | 선 색 |
|---|---|---|---|
| 장수·몬스터·NPC | **5~6px**, 끊김 없이 | 2~3px (옷 주름·이목구비) | 순검정 `#0c0c0c` 안팎 |
| 건물·소품·나무·바위 | 캐릭터보다 **얇게** (높이 대비 1.5~2%) | 1~2px | 순검정 대신 **각 물체의 짙은 색** (나무=짙은 녹, 돌=짙은 회, 목재=짙은 갈) |
| 바닥·길·물 | 선 없음 또는 아주 옅은 경계 | — | — |
| 이펙트 | 선 없음 또는 흰/밝은 테두리 | — | — |

**원칙: 화면에서 가장 굵은 선은 캐릭터.** 캐릭터가 배경 위로 튀어나와 보여야 한다.

## 3. 색

| 항목 | 기준 |
|---|---|
| 캐릭터 대표색 | 1인당 2~3개 (유비 적·금 / 관우 녹·적 얼굴 / 장비 흑·회·붉은 띠 / 조운 백·청) |
| 캐릭터 채도 (0~100) | 35~50 — 한 캐릭터만 튀거나(이전 관우 64) 흐리지(이전 장비 23) 않게 |
| 캐릭터 밝기 (0~100) | 35~45 |
| 그림자 색 | 검정을 섞지 말고 **기본색을 어둡고 조금 더 진하게** (빨강 → 어두운 적갈) |
| 하이라이트 | 작은 면 1개. 반짝임·광택 묘사 금지 |
| 금지 | 그라데이션, 재질 묘사(천 결·나뭇결 잔선), 노이즈, 외곽 발광 |
| 피부 | 유비 시안의 살구색 계열로 통일 (관우만 붉은 얼굴) |
| 바닥과의 대비 | 초원 바닥(밝기 약 50, 채도 약 60) 위에서 캐릭터가 먼저 보이게. 바닥보다 어두운 몸 + 순검정 선 |

밝기·채도는 그림의 불투명 픽셀 평균이다. 개발이 같은 방법으로 다시 잰다(9장).

## 4. 형태

- **큰 머리, 짧은 몸, 짧고 굵은 다리.** 손발은 둥근 덩어리. 손가락은 2~3개 덩어리로 충분
- 눈은 흰자 없이 **검은 점 또는 세로 짧은 선**, 크기는 머리 폭의 15~20%. 눈썹·수염은 굵은 단색 덩어리
- 작은 장식(무늬, 끈, 장신구)은 게임 크기에서 2px 이하가 되면 지운다. 대신 **실루엣으로 구분**되게 한다(관·두건·수염·무기 모양)
- 무기는 몸 밖으로 최대 0.5칸(50px). 큰 무기(언월도·장팔사모)는 짧게 줄여도 된다 — 원작도 무기를 몸 크기에 맞게 줄였다

## 5. 크기 표 (모두 350×350 캔버스, 발 (175,245) 기준)

| 대상 | 몸+머리 키 | 비고 |
|---|---|---|
| 장수 | **125~140px** | 기준 |
| 황건 졸병·창병·궁병 | 115~130px | 장수보다 조금 작게 |
| 주민 어른 | 105~125px | |
| 소년 | 90~100px | |
| 늑대 | 높이 70~85, 길이 110~130px | |
| 관해 (보스) | 160~180px | 장수의 1.3배, 몸 폭 넓게 |
| 장각 (보스) | 150~170px | 지팡이 포함 180px 이내 |

## 6. 확인 방법

1. 그림을 **실제 게임 크기(350 캔버스 → 화면에서 약 60~70px 높이)**로 줄여 본다. 얼굴·누구인지가 읽혀야 한다
2. 초원 바닥색 위, 흙길 위, 어두운 숲 위에 세워 본다
3. 검은 실루엣만으로 장수 넷이 구분되는지 본다
4. [유비 기준 시안](참고/기준/유비_새시안_기준.png)과 나란히 놓고 선 굵기·채도가 같은 게임처럼 보이는지 본다
