작성: 2026-10-29. 이미지 작업을 처음부터 다시 할 때 쓰는 **한 곳짜리 기준 묶음**이다. 캐릭터·몬스터·NPC·맵 그림과 모든 모션의 기준을 원작 《우르르 용병단》 게임 데이터를 직접 측정한 값으로 정리했다.

- 기존 `characters/`, `art/terrain/` 그림은 **그대로 둔다.** 새 그림이 승인되면 개발이 교체한다.
- 새로 그리는 그림은 이 폴더의 `작업/` 아래에 둔다(9장 참고). 승인 전에는 실행 파일을 바꾸지 않는다.
- 이 폴더의 숫자 중 **"원작 측정"이라고 적은 값은 실제 게임 파일에서 잰 값**이다. "목표"라고 적은 값은 측정을 바탕으로 정한 제작 기준이다.

## 내일 작업 순서 (권장)

1. **유비 원화 확정** — 기준 시안을 350×350 투명 PNG로 정리 (02, 09장)
2. **유비 숨쉬기 4장 + 이동 6장** — 06장 원작 수치대로. 게임에 넣어 튀는 느낌 확인
3. 관우·장비·조운 원화 → 숨쉬기·이동 (유비와 나란히 비교)
4. 황건 졸병 원화·숨쉬기·이동·사망 → 나머지 적
5. 주민 NPC
6. 맵 바닥·길 → 건물·소품 → 채집 나무·광석
7. 공격·스킬·채집 모션, 이펙트

원화 1장이 승인되기 전에 모션을 대량으로 만들지 않는다. **원화 → 숨쉬기·이동 → 게임 화면 확인 → 다음 캐릭터** 순서가 다시 그리는 비용이 가장 적다.
