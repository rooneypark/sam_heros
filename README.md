## 공격·스킬 제작 보류

사용자는 화면만 보고 동작을 추측하는 접근이 불충분하다고 판단하여 모션 작업을 중단했다. 스킬 분석을 충분히 마친 뒤 재개하기로 했다. 현재 공격·스킬의 확정 사양이나 승인된 애니메이션은 없다.

재개 시에는 원작의 실제 발동 조건, 준비→공격→복귀, 효과 궤적·범위·타이밍, 적의 접근·공격·피격 반응을 분석하고 관찰 사실과 신규 설계를 구분한다. 사용자가 다시 요청하기 전에는 분석·제작을 자동으로 진행하지 않는다.

## 정리 내역

불필요한 폴더는 프로젝트에서 제거하고 Windows 휴지통으로 이동했다. 영구 삭제 명령이 자동 승인 검토에서 차단되어 복구 가능한 방식으로 정리했다.

- 공격·스킬 모션 v1~v3의 GIF·영상·키포즈·효과 원화·렌더링 코드·검수 이미지·실행 기록·캐시 삭제.
- 모션 전용 참고 GIF, 프레임 추출 이미지와 미완성 분석 문서 삭제.
- 승인 조감도와 내용이 동일한 이전 산출물 사본 및 중복 목록 삭제. 제작 맥락은 디자인 가이드에 통합.
- 승인 이미지 7장과 원작 정적 참고 자료 7장은 원본 그대로 유지.

이 정리는 프로젝트 폴더에 적용한다. 대화에 이미 표시된 과거 이미지나 앱이 별도로 보관하는 생성 이력의 삭제를 의미하지 않는다.
