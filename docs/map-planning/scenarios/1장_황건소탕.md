# 1장 황건 소탕 — 확정 진행

정리 기준: 2026-10-27. 진행 확정 기준은 유지하고 신규 납품 유닛·등록 ID를 동기화했다.
[성장·진행 규칙](../SAMGUK_PROGRESSION.md)과 [미정 사항](../미정사항.md)을 함께 따른다.

## 기본 설정

황건적에게 붙잡힌 주민들을 구해 마을로 데려온다.
장비·관우는 포로가 아니며 주민 구출 활동에 자발적으로 합류한다.
마을과 황건적 소굴을 오가며 전투 성장·채집·건설·훈련을 진행하고 중간 보스와 최종 보스를 공략한다.

## 확정 진행 순서

| 순서 | 진행 |
|---|---|
| 1 | 시작 나레이션 후 유비가 사냥터에서 마을로 이동 |
| 2 | 마을에서 붙잡힌 주민들의 상황을 파악하고 구출에 나섬 |
| 3 | 주민을 구해 마을로 데려옴 |
| 4 | 장비가 등장해 다음 주민 구출을 제안하고 합류 |
| 5 | 유비·장비가 함께 추가 주민을 구출하고 마을로 귀환 |
| 6 | 관우가 등장해 합류하고 보스 토벌을 제안 |
| 7 | 전투·채집·건설·훈련으로 준비하며 지역을 확장 |
| 8 | 중간 보스 관해 공략 |
| 9 | 안개 너머 더 깊은 구역으로 진행 |
| 10 | 최종 보스 장각 공략 |

주민 구출은 풀어주는 행동과 마을 귀환을 구분한다.
장비·관우의 합류와 대화는 주민 귀환 진도에 연결한다.
안개는 지역 진행에 따라 걷히는 방향이며, 구체적인 개방 사건은 아직 미정이다.

## 대사 기준

짧고 캐주얼한 말투로 현재 상황과 다음 행동을 연결한다.
‘사람들·마을 사람들’, ‘도와줄게·같이 가자’처럼 친근하게 표현한다.
고전적인 어투는 사용하지 않는다. 시작 나레이션과 등장인물 대화를 사용한다.

장면별 정확한 대본은 최종 승인 전이므로 확정 문서에 수록하지 않는다.

## 개발 확인 기준

주민별 구출·마을 도착, 장비·관우 등장·합류, 관해·장각 격파 상태를 구별하고 저장한다.
귀환을 완료해야 후속 합류·목표가 진행되며 재접속이나 재방문으로 중복 지급·중복 합류가 일어나지 않아야 한다.
부대가 보스에게 패배해도 마을과 성장·채집 가능한 구역을 이용할 수 있어야 한다.

## 미정 사항

주민 수·배치·동행 방식·피격·사망 여부, 정확한 대사·연출 타이밍, 안개 해제 사건과 영역, 시설 개방 위치·시점, 적 수·레벨·맵 좌표·비용·보스 패턴·보상·다음 지역.


## 현재 동기화 판정

큰 진행 구조와 새 졸병·늑대·보스 배치는 일치한다. 주민·구출 지점에는 기존 NPC 참조가 남아 있고, 마을 귀환 판정·관해 격파와 다음 구역 통과 조건은 별도 연결·검증이 필요하다. 세부 근거와 개발 요구는 [동기화 점검](../SYNC_STATUS.md)을 따른다.

[조운](../units/SG_U0004.md)은 신규 등록됐지만 1장 합류 시점은 확정되지 않았다. 현재 유비 → 장비 → 관우 진행에 임의 삽입하지 않는다.
