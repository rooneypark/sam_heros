# 삼국히어로즈 성장·진행 확정 기획

정리 기준: 2026-10-26. 사용자 확정 내용만 수록한다. 기획 확정과 구현·검증 완료는 별개다.
미결정 항목은 [미정 사항](미정사항.md)에서 관리한다.

## 성장과 경제

| 항목 | 확정 내용 |
|---|---|
| 유저 EXP·레벨 | 별도 유저 경험치·유저 레벨과 상단 유저 EXP 게이지를 없앤다 |
| 장수 등급·조각 | 장수 희귀도 등급과 조각 기반 강화를 없앤다 |
| 장수 개인 성장 | 적과 전투하여 경험치를 얻고 자동 레벨업한다. 고기·조각·채집 자원을 강화 비용으로 소비하지 않는다 |
| 전투 보상 | 황건적·사냥개 처치 시 고기 대신 경험치로 표현한다 |
| 경험치 수령 | 출전 장수들이 함께 받는다 |
| 경험치 연출 | 알갱이가 장수들에게 흡수되고 체력바 아래 개별 경험치바가 찬다 |
| 레벨업 | 경험치바가 가득 차면 자동으로 레벨업한다 |
| 채집 | 필드에서 나무·광석을 채집한다 |
| 건설·훈련 | 나무·광석을 건설·거점 복구와 부대 공통 훈련에 사용한다 |
| 기능 개방 | 유저 레벨 대신 지역·거점·보스 진행으로 기능과 훈련 단계를 개방한다 |
| 진행 동기 | 파밍·육성으로 전력을 높여 다음 보스를 공략하고 다음 지역으로 나아간다 |

공동 경험치 수령을 전원 전액 지급이나 인원수 분할로 임의 해석하지 않는다. 지급량 방식은 미정이다.

## 1장 진행

유비 시작 → 사냥터에서 마을 도착 → 주민 구출·마을 귀환 → 장비 자발적 합류 → 장비와 추가 주민 구출·귀환 → 관우 자발적 합류 → 전투·채집·훈련으로 준비 → 관해 공략 → 장각 공략.

구출 대상은 황건적에게 붙잡힌 주민이다. 장비·관우는 포로가 아니라 구출 활동에 뜻을 함께하여 합류한다.
마을과 황건적 소굴을 오가며 성장하고 지역을 확장한다.

자세한 확정 순서는 [1장 시나리오](scenarios/1장_황건소탕.md)를 따른다.

## 장수 공격·스킬

| 장수 | 기본 공격 | 1차 스킬 A | 2차 스킬 B |
|---|---|---|---|
| [유비](units/SG_U0001.md) | 검으로 찌르기 | 두 검 X자 모으기·치유 | 두 검을 하늘로 올려 X자 모으기·보호막 |
| [관우](units/SG_U0002.md) | 청룡언월도로 베기 | 언월도를 휘둘러 X자 베기 | 청룡 검기: 크게 들어 지면으로 찍으며 크게 베기·전방 다수 적 검기 공격 |
| [장비](units/SG_U0003.md) | 장팔사모로 찌르기 | 서로 다른 두 지점 2연속 찌르기·범위공격 | 원형으로 한 번 크게 휘두르기·자신의 방어력 상승 및 주변 적 도발 |

1차·2차는 스킬 슬롯 구분이며 해금 레벨을 뜻하지 않는다. 2026-10-26 결정은 스킬 모션 변경이며 기본 공격과 기존 효과는 유지한다.

## 개발 전달 기준

기획자는 문서를 작성하고 개발자는 공통 문서를 기준으로 구현·검토한다.
기능의 세부 조건과 수치는 미정 목록에서 합의한 뒤 반영한다.
개발 완료 여부를 기획 확정 여부와 혼동하지 않는다.
