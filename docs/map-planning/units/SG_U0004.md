# 조운 (`SG_U0004`)

정리 기준: 2026-10-27. 승인 아트와 현재 유닛 등록을 반영한다. 전투 효과·밸런스·합류 사건은 별도 확정이 필요하다.

## 역할·등장

- 승인 무기는 **청공검**이다. 창을 사용하는 장수로 기재하지 않는다.
- 전투 EXP 성장·무등급·무조각 공통 규칙을 따른다.
- 합류 챕터·시점·역할은 미정이다. [1장](../scenarios/1장_황건소탕.md) 합류 대상으로 임의 추가하지 않는다.

## 공격·스킬

| 구분 | 승인 모션 | 게임 효과 확정 상태 |
|---|---|---|
| 기본 공격 | 청공검 기본공격, 7프레임 | 세부 베기 방향·타수·범위 미정 |
| 스킬 1 | 상승베기, 8프레임 | 피해·대상·범위·부가 효과 미정 |
| 스킬 2 | 상승회전검기, 8프레임 | 검기 이동 방식·범위·타수·피해 미정 |

‘상승베기·상승회전검기’는 승인 자료의 모션 명칭이다. 최종 게임 표시명과 효과까지 확정됐다는 의미는 아니다. 이동 6·숨쉬기 4프레임, 원화·초상화가 승인돼 있다. 사망 모션은 현재 납품 목록에 없다.

## 개발 확인 기준

현재 등록명은 `조운 Attack / Skill_01 / Skill_02`이며 원작 base 액션을 차용하고 있다. 모션 승인만으로 청공검 스킬 효과 구현 완료로 판정하지 않는다. 효과·표시명·합류 조건을 확정한 후 연결한다.
