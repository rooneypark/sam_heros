정리 기준: 2026-10-27. 공격·스킬 효과는 아래 확정 기획을 유지한다. 승인 모션과 게임 효과 구현 완료는 구별한다.

## 역할·등장

- 장팔사모를 사용하는 탱커.
- [1장](../scenarios/1장_황건소탕.md)에서 첫 주민 구출·마을 귀환 후 자발적으로 합류한다.
- 합류 후 다음 주민 구출을 제안하고 동행한다.
- 전투 EXP로 자동 성장하며 장수 등급·조각을 사용하지 않는다.

## 확정 공격·스킬

| 구분 | 확정 동작·효과 |
|---|---|
| 기본 공격 | 장팔사모로 찌르기 |
| 1차 스킬 A | 장팔사모로 서로 다른 두 지점을 한 번씩 찔러 총 2회 연속 공격. 범위공격 역할 유지 |
| 2차 스킬 B | 장팔사모로 원을 그리며 한 번 크게 휘두름. 자신의 방어력 상승·주변 적 도발 효과 유지 |

1차는 서로 다른 두 지점의 2연속 찌르기, 2차는 원형 궤적의 큰 휘두르기 1회로 구별한다. 두 지점의 정확한 방향·배치는 미정이다. 2차의 공격 피해 추가는 확정하지 않았으며 보호막 효과도 포함하지 않는다.
보스에게는 도발이 적용되지 않는다. 이 예외는 공통 문서에 기록된 2026-10-24 사용자 결정에 따른다.

## 개발 확인 기준

1차는 서로 다른 두 지점을 찌르는 동작과 각각의 타격 시점에 범위 피해를 연결한다. 2차는 큰 원형 휘두르기 1회에 방어력 상승과 도발을 연결한다.
도발 중 적의 타깃이 장비를 향하고 종료 후 정상 선택으로 복귀하는지, 방어력 상승이 종료 후 해제되는지, 보스가 도발에 영향받지 않는지 확인한다.
확정되지 않은 제작 수치를 기획값으로 사용하지 않는다.
