# 유비 (`SG_U0001`)

정리 기준: 2026-10-27. 공격·스킬 효과는 아래 확정 기획을 유지한다. 승인 모션과 게임 효과 구현 완료는 구별한다.

## 역할·등장

- 자웅일대검을 사용하는 치유·지원 장수.
- [1장](../scenarios/1장_황건소탕.md)의 시작 장수.
- 전투 EXP로 자동 성장하며 장수 등급·조각을 사용하지 않는다.

## 확정 공격·스킬

| 구분 | 확정 동작·효과 |
|---|---|
| 기본 공격 | 검으로 찌르기 |
| 1차 스킬 A | 두 검을 X자로 모으는 동작. 치유 효과 유지 |
| 2차 스킬 B | 두 검을 하늘로 올려 머리 위에서 X자로 모으는 동작. 보호막 효과 유지 |

1차는 X자로 모으기, 2차는 하늘로 들어 올려 X자로 모으기로 높이와 준비 동작을 구별한다. 승인 제작 자료에서는 1차를 가슴 앞 교차, 2차를 머리 위 교차로 구분한다.
스킬의 최종 명칭·대상·수치·범위·타이밍은 확정하지 않았다.

## 미정 사항

찌르기 타수·사거리·공격 간격, 치유 대상·회복량·범위, 보호막 대상·흡수량·지속시간, 쿨타임·발동 조건·해금 레벨, 세부 프레임·FX·적용 시점.
[공통 미정 목록](../미정사항.md)을 함께 확인한다.

## 개발 확인 기준

기본 공격은 적에게 피해를 주는 찌르기다. 스킬 A는 X자 모으기와 치유, 스킬 B는 머리 위 X자 모으기와 보호막을 연결한다. 이번 결정은 스킬 모션 변경이며 효과 변경은 아니다.
합의한 수치·대상·시점에 맞춰 동작과 효과가 일치하는지 확인한다. 확정되지 않은 제작 수치를 기획값으로 사용하지 않는다.
