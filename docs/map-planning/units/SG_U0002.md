# 관우 (`SG_U0002`)

정리 기준: 2026-10-27. 공격·스킬 효과는 아래 확정 기획을 유지한다. 승인 모션과 게임 효과 구현 완료는 구별한다.

## 역할·등장

- 청룡언월도를 사용하는 공격 장수.
- [1장](../scenarios/1장_황건소탕.md)에서 장비와 추가 주민을 구해 마을로 귀환한 뒤 자발적으로 합류한다.
- 합류 후 관해·장각 토벌을 제안한다.
- 전투 EXP로 자동 성장하며 장수 등급·조각을 사용하지 않는다.

## 확정 공격·스킬

| 구분 | 확정 동작·효과 |
|---|---|
| 기본 공격 | 청룡언월도로 베기 |
| 1차 스킬 A | 청룡언월도를 휘둘러 X자로 베기 |
| 2차 스킬 B — 청룡 검기 | 언월도를 크게 들어 땅으로 찍으면서 크게 베기. 검기가 앞으로 날아가 여러 적을 공격하는 효과는 유지 |

1차는 무기의 궤적이 X자를 이루는 베기, 2차는 크게 들어 지면으로 찍으며 크게 베는 동작이다. 사용자가 나열한 두 번째 동작은 2차 스킬로 정리한다. X자 궤적의 베기 순서·타격 횟수는 미정이다.
2차에서 관우 자신이 돌진하지 않는다. 청룡 검기 명칭은 확정이며 기본 공격·1차의 최종 명칭은 미정이다.

## 미정 사항

기본 공격 타수·각도·거리, 1차 X자 베기 순서·타격 횟수·범위·피해·대상 수, 2차의 지면 접촉·검기 발사 시점, 검기 외형·이동 거리·속도·폭·다수 타격 판정, 최대 대상 수·피해량, 쿨타임·발동 조건·해금 레벨·세부 프레임.
[공통 미정 목록](../미정사항.md)을 함께 확인한다.

## 개발 확인 기준

기본 베기·1차 X자 베기·2차 크게 들어 지면으로 찍으며 베기를 구별한다.
이번 결정은 스킬 모션 변경이며 기존 공격 효과는 유지한다. 2차의 새 동작과 전방 검기 발사를 연결하고 검기가 합의된 여러 적에게 피해를 주는지 확인한다. 확정되지 않은 제작 수치를 기획값으로 사용하지 않는다.
