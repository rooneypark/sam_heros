# 실제 나무 채집 테스트

실행: http://127.0.0.1:8124/web/motion.html?units=SG_U0001&test=gather

- 모션체커의 **실제 나무 채집**을 켜면 선택 목록 첫 번째 채집 가능 캐릭터가 나무로 이동해 채집한다.
- 실제 게임의 채집 행동 트리, 이동, 스킬 애니메이션 이벤트, ResourceActor.Damage를 사용한다. 타격 시점을 미리보기 시계로 강제하지 않는다.
- 나무 HP, 실제 피격 횟수, 거리, 마지막 피격 경과시간을 표시한다.
- 일시정지, ▶| 단계 진행, 0.25/0.5배 재생 지원. 벌목 후 **나무 테스트 다시 시작**으로 초기화한다.
- 다른 캐릭터: 모두 지우기 후 캐릭터 추가. 우르르 용병단 탭에서도 시험 가능하다.
- 아래 프레임 카드는 별도 반복 미리보기이며 실제 접근 시간이 포함된 위 게임 화면과 동기화하지 않는다.
- 이 화면은 독립 시험장이다. 챕터 맵 파일과 캐릭터 그림을 수정하지 않는다.

검증: 유비 접근 거리 2.20→0.53, 나무 HP 4→0 및 실제 타격 4회/벌목 확인. 정지 상태 초기화와 단계 진행 확인. 기존 custom-motion 및 pack-frame 테스트 통과.
