# 기획 작업 규칙 (기획자용)

> 2026-10-24 경로 변경: 기획자·개발자의 공통 기획 원본은 [work/sam_heros2/docs/planning](C:/Users/pms10/Documents/work/sam_heros2/docs/planning/README.md)이다. 아래 내용은 기존 협업 구조의 참고 기록이다. 신규 기획과 수정은 새 위치의 전체·유닛·시나리오 문서에 반영한다.

## 역할 범위 — 2026-10-24 사용자 지시

이 대화의 담당은 기획자다. 원작 게임·엔진·맵 메이커 코드를 직접 수정하지 않는다. 합의한 규칙, 원작 대비 변경점, 미정 사항, 개발 요청과 완료 기준을 기획 문서로 정리해 개발자에게 전달한다. 문서 작성 요청을 엔진 구현 요청으로 확대하지 않는다. 실행 데이터·수치 오버라이드도 현재는 적용하지 않는다.

이 원칙은 후속 기획 작업에도 계속 적용한다. 사용자가 매번 같은 제한을 반복할 필요가 없다. 기획서의 ‘제거·추가·개편’은 개발자에게 전달할 요구사항으로 기록한다.

전체 구조는 [COLLABORATION.md](../COLLABORATION.md) 참고.

## 기준 자료

- **[게임 체계 총정리](GAME_SYSTEMS.md)** — 원작의 진행·성장·경제·전투 규칙과 수치, 삼국히어로즈용으로 바꾸는 방법(`content/samguk/tables/overrides.json`). 먼저 읽는다.
- **[성장·진행 개편 기획서 — 개발자 전달용](SAMGUK_PROGRESSION.md)** — 유저 EXP 제거, 무등급·무조각·구출 후 전투 자동 성장, 나무·광석의 건설·부대 훈련 용도, 지역·보스 개방안, 일일 임무 제안과 개발 요청. 게임 반영 전이다.
- `catalog/우르르용병단_성장_진행_데이터북.xlsx` — 퀘스트·건설·레벨·성장·주점·명성·기여·훈련·일일 미션·자원·드롭·능력치 표 (20개 시트).

- `catalog/우르르용병단_유닛_스킬_카탈로그.xlsx` — 원작 유닛 856종의 레벨별 스킬, 스킬 동작, 이펙트, 투사체, 발동 조건, 범위, 상태이상, 연계 스킬. 각 시트의 노란 **기획 메모** 칸에 삼국 적용 의견을 적는다. 원작 데이터라 git에 올리지 않는다(.gitignore).
- 맵 메이커 — 카탈로그에서 고른 유닛·레벨을 바로 배치해 전투로 확인한다.
