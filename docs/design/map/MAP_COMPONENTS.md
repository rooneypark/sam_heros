# 맵 공용 컴포넌트 제작 가이드 (디자이너용)

작성일: 2026-10-23.

- 이 문서는 지형(잔디·길·물·산), 집·울타리·소품 같은 **맵 부품**을 그려 맵 메이커에 넣는 방법을 정리한다.
- 수치는 모두 원작 맵 데이터에서 잰 값이다.
- 먼저 [AGENTS.md](../../../AGENTS.md)와 [기본 스타일](../SAMGUK_BASE_STYLE.md)을 읽는다. 지형은 승인 01~04번 컷이 기준이다.

## 1. 맵의 구조

원작 맵은 아이소메트릭 격자 위에 레이어 5장을 겹친 구조다. 뒤 레이어부터 앞으로 그려진다.

| 레이어 | 격자 | 그리는 것 | 통행 |
|---|---|---|---|
| `mapData` 바닥 | 지형 칸 | 잔디·던전 바닥 | 바닥이 있는 칸만 걸을 수 있음 |
| `roadData` 길 | 지형 칸 | 흙길·모래밭 | 걸을 수 있음 |
| `waterData` 물 | 지형 칸 | 연못·강 | **막힘** |
| `decoData` 장식 | 장식 칸 (지형 칸의 1/3) | 집·울타리·바위·꽃·소품 | 부품마다 지정 (`blocks`) |
| `blockData` 산·절벽 | 지형 칸 | 산·절벽·큰 바위 | **막힘** |

- **지형 칸:** 화면에서 가로 400px × 세로 240px 마름모다. 120px가 1 월드 단위이고, 한 칸은 3.32 × 2.0 단위다.
- **장식 칸:** 지형 칸의 1/3 크기(133 × 80px 마름모)다. 집이나 소품은 이 칸 하나에 놓인다.
- **카메라:** 게임 화면은 세로 26 단위(지형 칸 13개 높이)를 보여 준다. 캐릭터 키는 약 1.35 단위로, 지형 칸 하나보다 작다.
- **방향 표기:** 이 문서의 ↗↖↙↘는 마름모 격자의 네 변 방향이다. 화면 기준 우상·좌상·좌하·우하다.

## 3. 부품 종류와 그리는 규칙

### 3-1. 바닥 (잔디, 마당 흙바닥 등) — `type: "random"`
- 400×240 마름모를 2~4장 그린다. 엔진이 칸마다 무작위로 골라 깔아 반복이 덜 보인다.
- 마름모 네 꼭짓점까지 꽉 채운다. 이웃 칸과 이어지도록 가장자리 색과 무늬를 맞춘다.
- 기준점은 가운데 `[0.5, 0.5]`, ppu는 120이다.

### 3-2. 흙길 — `type: "road"` (12조각, 순서 고정)
선처럼 이어지는 길이다. 이웃 칸(변으로 맞닿은 칸)에 따라 엔진이 조각을 고른다.

| 번호 | 역할 | 번호 | 역할 |
|---|---|---|---|
| 0 | 직선 ↙↗ | 6 | 모퉁이 ↗+↖ |
| 1 | 직선 ↙↗ 변형 (10% 확률) | 7 | 모퉁이 ↙+↘ |
| 2 | 직선 ↖↘ | 8 | 모퉁이 ↗+↘ (↙+↖는 이 조각을 180° 회전) |
| 3 | 직선 ↖↘ 변형 (10%) | 9 | T자, ↗쪽 막힘 (↙ 막힘은 180° 회전) |
| 4 | 끝: ↙쪽에서 들어와 끝남 (↗쪽 끝은 180° 회전) | 10 | T자, ↖쪽 막힘 (↘ 막힘은 180° 회전) |
| 5 | 끝: ↖쪽에서 들어와 끝남 (↘쪽 끝은 180° 회전) | 11 | 십자 (사방) |

- 길이 칸의 변 가운데에서 이어지도록 폭을 일정하게 유지한다. 폭은 `road_rd_r_00.png`의 원작 길에 맞춘다.
- 180° 회전으로 재사용하는 조각은 회전해도 어색하지 않게 그린다. 그림자나 빛 방향이 한쪽으로 치우치지 않게 한다.

### 3-3. 물·모래밭 (연못, 강, 공터) — `type: "pond"` (13조각, 순서 고정)
면으로 채워지는 영역이다. **2×2칸 이상**이어야 그려진다(맵 메이커가 자동으로 2×2로 칠한다).

| 번호 | 역할 | 번호 | 역할 |
|---|---|---|---|
| 0 | 안쪽 꼭짓점 · 서(←) | 7 | 가장자리 · ↗쪽 물가 |
| 1 | 안쪽 꼭짓점 · 동(→) | 8 | 바깥 꼭짓점 · 동(→) |
| 2 | 안쪽 꼭짓점 · 북(↑) | 9 | 바깥 꼭짓점 · 서(←) |
| 3 | 안쪽 꼭짓점 · 남(↓) | 10 | 바깥 꼭짓점 · 남(↓) |
| 4 | 가장자리 · ↘쪽 물가 | 11 | 바깥 꼭짓점 · 북(↑) |
| 5 | 가장자리 · ↖쪽 물가 | 12 | 가운데 (사방이 물) |
| 6 | 가장자리 · ↙쪽 물가 | | |

- 가운데(12)는 400×240 마름모를 꽉 채운다. 가장자리(4~7)는 한 변에만 물가 띠를 그린다.
- 바깥 꼭짓점(8~11)은 볼록한 모서리, 안쪽 꼭짓점(0~3)은 오목한 모서리에 작은 물가 조각을 그린다.
- 물가 띠의 폭과 색을 13장 모두 같게 해야 이음새가 보이지 않는다. `pond_wt_r_00.png`를 옆에 두고 위치를 맞춘다.

### 3-4. 산·절벽 — `layer: "blockData"`, `type: "random"` 또는 `"single"`
- 원작 산은 400×400px이고 기준점은 `[0.5, 0.3]`(아래쪽 마름모 중심)이다. 칸 위로 솟은 부분이 위로 넘친다.
- 이 레이어는 항상 통행이 막힌다.

### 3-5. 집·건물·울타리·소품 — `layer: "decoData"`, `type: "single"`
한 장짜리 그림이다. 장식 칸 하나에 놓이고, 크기는 원작 같은 용도의 소품에 맞춘다.

| 원작 소품 | 크기 (px) | 기준점 | 비고 |
|---|---|---|---|
| 폐가 `Object_abandonedhouse` | 283×272 | 0.5, 0.5 | 작은 집 한 채. 지형 칸의 약 0.85배 폭 |
| 우물 `Object_well` | 198×191 | 0.5, 0.3 | |
| 울타리 `Object_town_fence_1` | 120×140 | 0.5, 0.3 | 한 칸짜리. 이어서 놓아 울타리를 만든다 |
| 통 `Object_barrel` / 항아리 `Object_jar` | 76×106 / 78×86 | 0.5, 0.5 | |
| 작은 바위 산 `Object_Mountain_small` | 556×383 | 0.5, 0.5 | |

- ppu는 100이다(캐릭터와 같음). 캐릭터가 약 135px 키이니, 초가집 문 높이를 캐릭터 키에 맞춘다.
- **기준점은 바닥에 닿는 중심점**이다. 지붕 끝이 아니라 집이 땅에 앉은 마름모의 중심이며, 비율로 적는다(가로 0.5, 아래에서 몇 %). 이 점이 장식 칸 중심에 놓인다.
- **앞뒤 가림:** 장식은 아래(화면 앞)에 있는 것이 위(뒤)의 것을 가린다. 큰 건물은 지붕이 뒤쪽 칸을 덮도록 위로 높게 그려도 된다.
- **통행:** 사람이 지나갈 수 없는 것(집, 울타리, 바위, 수레)은 `"blocks": true`로 둔다. 건물처럼 장식 칸 하나보다 크면 `"footprint": [가로칸, 세로칸]`(장식 칸 단위)을 적는다. 그 범위가 막힌다. 283px 집이면 `[3, 3]` 정도다.
- **겹치는 큰 소품:** 지붕 처마, 깃발대처럼 위로 길게 뻗은 것은 기준점만 바닥에 맞으면 된다.
- **방향 짝 (울타리·벽·문·표지판):** 원작은 맵에 회전 정보를 저장하지 않는다. 대신 **좌우로 뒤집은 그림을 별도 타일로 둔다**(예: 마을 울타리 `br_122`(↗ 방향)/`br_123`(↘ 방향), 바리케이드 `br_00`/`br_01`). 원작에는 이런 짝이 75쌍 있다. 이어지는 부품은 **두 방향을 모두 그리고**, `tiles.json`의 한쪽에 `"pair": "반대쪽 id"`를 적는다. 맵 메이커 팔레트에 ⟲ 버튼이 생기고, R 키로 붓이나 놓인 부품의 방향을 바꿀 수 있다. 좌우 대칭 그림을 단순 반전으로 만들면 빛 방향이 반대가 되므로, 그림자 위치를 다시 맞춘다.

### 3-6. 공통
- 투명 PNG, sRGB. 파일명은 영문·숫자·밑줄을 쓴다.
- 굵은 검은 외곽선과 단순한 색면을 쓴다. 승인 01~04번 컷의 초가·목책·술독·곡식 포대 표현을 따른다.
- 그림자는 부품 그림 안에 짧게 포함한다(원작 소품도 바닥 그림자를 그림 안에 그렸다).

## 4. 맵 메이커에 등록하기 — `content/samguk/tiles.json`

```json
{
  "version": 1,
  "tiles": [
    { "id": "sg_grass", "name": "마을 잔디", "layer": "mapData", "type": "random",
      "sprites": ["art/tiles/grass_0.png", "art/tiles/grass_1.png", "art/tiles/grass_2.png"] },
    { "id": "sg_road", "name": "마을 흙길", "layer": "roadData", "type": "road",
      "sprites": ["art/tiles/road_00.png", "…", "art/tiles/road_11.png"] },
    { "id": "sg_pond", "name": "냇물", "layer": "waterData", "type": "pond",
      "sprites": ["art/tiles/pond_00.png", "…", "art/tiles/pond_12.png"] },
    { "id": "sg_house_thatch_01", "name": "초가집", "layer": "decoData", "type": "single",
      "sprite": "art/objects/house_thatch_01.png", "pivot": [0.5, 0.18], "blocks": true, "footprint": [3, 3] },
    { "id": "sg_fence_01", "name": "목책", "layer": "decoData", "type": "single",
      "sprite": "art/objects/fence_01.png", "pivot": [0.5, 0.3], "blocks": true, "pair": "sg_fence_02" },
    { "id": "sg_fence_02", "name": "목책 (반대 방향)", "layer": "decoData", "type": "single",
      "sprite": "art/objects/fence_02.png", "pivot": [0.5, 0.3], "blocks": true }
  ]
}
```

| 필드 | 뜻 |
|---|---|
| `id` | 고유 이름 (`sg_` + 영문). 맵 파일이 이 이름으로 부품을 기억하므로 바꾸지 않는다 |
| `name` | 팔레트에 보일 이름 |
| `layer` | 1절 표의 레이어 |
| `type` | `single`(한 장) · `random`(변형 여러 장) · `road`(12조각) · `pond`(13조각) |
| `sprite` / `sprites` | 그림 경로. `road`·`pond`는 **3절 표의 번호 순서대로** 나열 |
| `pivot` | 기준점 `[가로, 아래에서]` 비율. 생략하면 바닥·길·물 `[0.5, 0.5]`, 산·장식 `[0.5, 0.3]` |
| `ppu` | 생략하면 지형 레이어 120, 장식 100 |
| `blocks`, `footprint` | 3-5절 |
| `pair` | 반대 방향 짝 부품의 `id` (울타리·벽·문). 한쪽에만 적어도 된다 |

등록한 뒤 맵 메이커를 새로고침하면 **지형 → 삼국** 탭에 나온다. 칠하고 놓고 실행해서 걸어 보면서 확인한다.
- **빨간 점선 칸:** 규칙상 그려지지 않는 칸이다. 혼자 떨어진 길, 2×2보다 작은 물이 여기에 해당한다. 맵 메이커가 표시해 준다.
- **원작 부품과 섞기:** 같은 맵에 원작 부품을 섞어도 된다. 다만 최종 맵에서는 삼국 부품으로 바꾼다.

## 5. 1장 「황건 소탕」 맵에 필요한 부품 (의뢰 목록)

승인 컷 01(마을 입구), 02(주막 앞 길), 03(황건군 초소), 04(마을 조감도) 기준이다.

| 구분 | 부품 | type | 비고 |
|---|---|---|---|
| 지형 | 마을 잔디 3변형 | random | 은은한 마름모 색 구획 (04번 컷) |
| 지형 | 마을 흙길 12조각 | road | 넓은 베이지 길. 입구 → 주막 → 초소를 잇는 한 줄기 |
| 지형 | 공터·마당 흙바닥 13조각 | pond | 주막 앞, 초소 마당 |
| 지형 | 냇물 13조각 | pond | 마을 옆 개울 (선택) |
| 지형 | 언덕·숲 덩어리 | random (blockData) | 맵 가장자리를 막는 벽 역할 |
| 건물 | 초가집 2~3종, 주막, 대장간 | single + blocks + footprint | 문 방향은 길 쪽(화면 앞) |
| 건물 | 황건군 막사(천막) 2종, 망루 | single + blocks + footprint | 03번 컷 |
| 울타리 | 목책 직선 2방향(↙↗, ↖↘), 모서리, 문 | single + blocks + pair | 한 장식 칸 단위로 이어 붙인다. 두 방향을 `pair`로 묶는다 |
| 소품 | 술독, 곡식 포대, 수레, 장작더미, 우물 | single (+ blocks) | 벽·울타리 주변에 묶어 놓는다 |
| 소품 | 황색 깃발, 바리케이드, 모닥불 | single (+ blocks) | 초소 |
| 장식 | 풀·꽃·작은 돌 | single (blocks 없음) | 드문드문 |

**작업 순서 권장**
1. 잔디 → 흙길 → 마당 흙바닥 순서로 그린다. 바닥이 정해져야 건물 색을 맞출 수 있다.
2. 흙길 12조각은 0번(직선)과 11번(십자)을 먼저 그린다. 맵 메이커에서 이어지는지 본 다음 나머지를 그린다.
3. 건물·울타리·소품을 그린다.
4. 맵 메이커에서 맵을 그리고 저장한다(`maps/chapter-1/map.json`). 유비·관우·장비와 황건적을 배치하고 실행해 동선과 전투 공간을 확인한다.

## 6. 아직 지원하지 않는 것 (개발 요청)

- **원작 건설 건물:** 원작의 건설·퀘스트 건물(건설하기, 주점, 훈련소처럼 상호작용하는 것)은 맵 메이커 팔레트로는 아직 배치할 수 없다. 1장 맵처럼 맵 파일의 `Buildings`·`buildingDefs`에 개발자가 넣는다([1장 맵 가이드](../maps/1장_황건소탕_MAP_GUIDE.md) 2절). 맵 메이커 실행 모드에서는 아직 누를 수 없다.
- **삼국 부품은 지금 맵 메이커에서만 읽는다.** 게임 화면(main)에서도 쓰려면 개발 요청이 필요하다.
- **애니메이션 부품:** 원작 `AnimatedTile`처럼 움직이는 부품(모닥불 불꽃, 펄럭이는 깃발)은 개발자에게 요청한다. `type: "animated"`를 추가할 수 있다. 그 전까지는 한 장(`single`)으로 그린다.
