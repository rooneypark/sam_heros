- 실행해서 보기: `http://127.0.0.1:8124/samguk/docs/design/intro/intro_prototype.html` (서버 실행 중일 때)
- 게임에서 보기: `run_samguk.bat` → 첫 화면
- 시안 코드: `sam_heros2/web/src/packs/chapter1/introSplash.js` (타이밍 원본은 `STEPS`)

## 콘셉트

원작처럼 **영웅이 잔상과 긴 그림자를 끌며 달려와 착지**하는 박력을 살리되, 배경·로고·연출은 삼국지 분위기로 새로 구성한다. 원작 화면·로고·배경 그림을 가져오지 않는다.

- 분위기: 붉은 노을, 먹빛 산 실루엣, 떠오르는 불티 — "난세의 시작"
- 주인공: 도원의 세 영웅 유비·관우·장비. 기존 승인 원화를 쓰는 게임 그림체 그대로
- 마무리: 로고가 도장처럼 쾅 찍히는 손맛(섬광 + 흔들림)

## 장면 순서 (세로 9:19.5 화면)

| 시간(초) | 장면 | 디자이너 제작 포인트 |
|---|---|---|
| 0.0 | 검은 화면 | 로딩 중에도 원작 장수가 비치지 않게 |
| 0.15~1.2 | 붉은 하늘이 밝아지고 해가 튀어 오르며 커짐. 먹빛 산 2겹이 아래에서 올라옴. 불티가 천천히 위로 | 배경 1장(하늘·해·산 레이어 분리), 불티 파티클 |
| 0.9 | **관우**: 화면 오른쪽 밖 → 왼쪽 자리로 0.4초 질주. 몸 뒤에 검은 실루엣 잔상 3개, 바닥 그림자가 길게 늘어났다가 몸 밑으로 줄어듦 | 질주 포즈 1~2장(또는 run 프레임), 실루엣 잔상, 그림자 |
| 1.3 | 관우 착지: 아래로 눌렸다(가로↑세로↓) 튀어 올랐다 복귀하는 **통통 튀는 착지**, 발밑 흙먼지. 이름패 `관우 / 운장` | 착지 포즈(위엄 있는 정지 자세), 먼지, 이름패 디자인 |
| 1.35 | **장비**: 같은 방식, 오른쪽 자리 | 장비 정지 포즈 |
| 1.85 | **유비**: 가운데, 두 장수보다 조금 크게 | 유비 정지 포즈(주인공) |
| 2.7 | 흰 섬광 0.35초 → **로고 `삼국히어로즈`**가 크게(2.4배)에서 쾅 찍히며 살짝 작아졌다 정착, 화면 0.3초 흔들림. 위 작은 글씨 `도원의 세 영웅`, 아래 붉은 도장 `1장 황건 소탕` | **로고 타이틀 그림(최우선)**, 도장 낙관 |
| 3.4~ | `화면을 터치하세요` 깜박임(1.2초 주기) | 문구 서체 |
| 탭 | 0.5초 페이드 아웃 → 게임의 `1장 / 황건 소탕` 제목 카드 → 나레이션 | — |

연출 중 화면을 탭하면 남은 연출을 건너뛰고 완성된 타이틀 화면으로 바로 갑니다. 한 번 더 탭하면 시작합니다.

## 납품 요청 (디자이너)

| 산출물 | 규격 제안 | 비고 |
|---|---|---|
| 로고 `삼국히어로즈` | 투명 PNG, 가로 1200px 이상 | 시안은 시스템 글꼴 + 테두리로 임시 표현 |
| 배경 | 1080×2340 세로, 하늘/해/산(먼)/산(가까운)/땅 레이어 분리 PNG | 레이어가 따로 움직이게 |
| 세 장수 타이틀 포즈 | 장수별 정지 1장(필요하면 질주 1장), 투명 PNG | 게임 원화 그림체. 크기는 화면 높이 약 30% |
| 이름패·도장 | 투명 PNG | `관우 운장`, `장비 익덕`, `유비 현덕`, `1장 황건 소탕` |
| 애니메이션(선택) | 위 타이밍표대로 만든 영상 또는 프레임 | 영상이면 세로 9:19.5, 5초 이내 |

그림만 오면 개발에서 위 타이밍으로 조립할 수 있습니다. 영상으로 오면 영상 재생으로 바꿉니다.

## 결정 필요

- 장수 자(字) 표기(운장·익덕·현덕)를 이름패에 넣을지
- 로고 아래 도장 문구를 장마다 바꿀지(`1장 황건 소탕` → 다음 장 이름)
- 매 실행마다 보여줄지, 처음 한 번만 보여주고 이후 짧게(로고만) 할지 — 현재 시안은 매 실행
