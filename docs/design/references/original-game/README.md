# 원작 디자인 근거 자료

보관일: 2026-10-23 (Asia/Seoul)

이 폴더는 디자인 논의 중 실제로 열어 확인했던 《우르르 용병단》 플레이어 리뷰의 스크린샷을 보관한다. 생성 이미지가 아니다. 다운로드 파일을 재편집하지 않고 그대로 복사했다. 일부 자료는 게시자가 잘라내거나 여러 화면을 합친 이미지이므로 전체 원본 화면으로 간주하지 않는다.

이미지 CDN 주소는 만료되는 서명 쿼리가 포함되어 있었으므로 지속적인 출처 링크는 위 게시물 주소로 남긴다. 게시물에서 이미지가 삭제되어도 이 폴더의 파일로 당시 검토 근거를 확인할 수 있다.

## 디자인 규칙과 근거의 연결

- **캐릭터 선·얼굴·체형:** 01, 02, 03, 04를 확인하고 승인된 삼국지 영웅 3컷과 비교한다.
- **초록 지면·흙길·수풀·여백:** 03, 04, 06을 확인하고 승인된 카메라 장면 3컷과 비교한다.
- **시설의 기능 표현:** 06, 07을 참고한다. 삼국지 주막·대장간·창고의 구체적 디자인은 프로젝트에서 만든 것이며 원작에 존재한다고 단정하지 않는다.
- **UI:** 01~07은 서로 다른 상황과 화면 일부만 보여준다. 새로운 UI 작업은 해당 화면의 충분한 원작 자료를 추가 확보한 뒤 진행한다.
- **배율과 화면비:** 세로 2:3 및 영웅 높이 약 10~12%는 사용자 승인 목업의 작업 기준이다. 이 자료로 검증한 원작의 고정 수치가 아니다.
- **전체 조감도:** 승인된 전체 지도는 프로젝트 공간 배치 기준이다. 원작 스크린샷이나 원작의 기본 플레이 카메라로 취급하지 않는다.

## 사용 절차

1. [디자인 가이드](../../SAMGUK_BASE_STYLE.md)와 작업 유형에 맞는 승인 이미지를 확인한다.
2. 이 목록에서 관련 원작 파일을 직접 열어 표현과 출처를 대조한다.
3. 이미지 생성에는 승인 이미지를 전달하고, 원작 표현을 다시 맞추는 작업에는 관련 원작 자료도 함께 전달한다. 각 이미지의 역할을 프롬프트에 구분한다.
4. 원작과 승인 목업 사이 차이를 발견하면 원작 관찰 사실과 프로젝트의 승인 선택을 구분해 기록한다. 사용자 승인 스타일을 임의로 덮어쓰지 않는다.
5. 추가 자료를 수집하면 파일, 출처, 확인일, 사용 목적, 화면 잘림/해상도 한계를 함께 기록한다.

이 자료는 제3자 게임/게시물에서 수집한 디자인 참고 자료이며 프로젝트가 새로 제작한 게임 자산과 구분한다.
