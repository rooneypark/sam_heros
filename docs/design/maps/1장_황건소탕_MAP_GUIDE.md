## 3. 코덱스가 할 일

1. **지형 다듬기:** 산 경계가 계단처럼 각져 있다. 자연스럽게 깎는다. 마을 울타리는 길이 지나는 곳만 비워 두었는데, 울타리 조각 방향(br_122/br_123)이 맞지 않는 곳을 고친다.
2. **장식 채우기:** 마을(폐가 → 일부는 무너진 집, 빨래·장작더미 등), 포로 지점(묶인 말뚝·우리), 초소(깃발·창 거치대), 소굴(동굴 입구 느낌)을 원작 장식 타일로 채운다. 길·다리·건물 자리·NPC 자리·적 배치는 옮기지 않는다.
3. **나무:** 맵 메이커 "나무"는 채집 자원이다. 숲 경계 장식용 나무는 장식 타일(br_136~147)을 쓴다. 채집 나무 수는 줄이지 않는다(다리·훈련소 재료).
4. **유지할 것:** 구역 순서와 길 연결, 첫 구출 장소가 마을에서 바로 갈 수 있는 열린 길이라는 점, 막힌 길 재료(나무·광석)가 막힌 길 너머가 아니라 이미 열린 쪽에 있다는 점.
5. 확인: 맵 메이커에서 열어 조감도와 구역 위치가 같은지, 길이 끊긴 곳이 없는지 본다.

## 4. 공용 컴포넌트(맵 부품)가 없으면 만들어서 넣기

이 맵은 지금 **원작 부품**(`g_r_00`, `obj_000` 등)으로 칠해져 있다. 삼국 부품이 없는 것은 코덱스가 새로 그려 등록한 뒤 바꿔 끼운다. 그리는 규칙(크기·기준점·조각 순서·통행)은 [맵 공용 컴포넌트 제작 가이드](../map/MAP_COMPONENTS.md)를 따른다.

### 4-2. 만든 부품을 맵 메이커에 추가하는 곳

1. **그림 파일:** 바닥·길·물·산은 `art/tiles/`, 집·울타리·소품은 `art/objects/`에 넣는다. 영문·숫자·밑줄 파일명.
2. **등록:** `content/samguk/tiles.json`의 `"tiles"` 목록에 한 줄씩 추가한다. 파일이 없으면 [MAP_COMPONENTS.md 4절](../map/MAP_COMPONENTS.md)의 예시로 새로 만든다. `id`는 `sg_`로 시작하고 한 번 정하면 바꾸지 않는다(맵 파일이 id로 부품을 기억한다).
3. **확인:** 맵 메이커를 새로고침하면 **지형 → 삼국** 탭에 나온다. 칠해 보고, 실행해서 걸어 보며 통행(`blocks`)을 확인한다.

### 4-3. 1장 맵에 바꿔 끼우기

- **칠해서 바꾸기:** 맵 메이커에서 1장 맵을 열고 삼국 탭의 부품으로 덮어 칠하거나 놓은 뒤 저장한다(저장 위치 `content/samguk/maps/1장_황건소탕.map.json`).
- **한꺼번에 바꾸기:** 맵 파일에서 4-1 표의 원작 이름을 삼국 `id`로 바꾼다. 예: `"n":"obj_000"` → `"n":"sg_house_thatch_01"`. 바닥·길·물·산처럼 칸 수가 많은 것은 이 방법이 빠르다. 바꾼 뒤 맵 메이커에서 열어 확인한다.
- 집·건물은 원작보다 크게 그렸으면 이웃 장식과 겹치는지 보고 자리만 조금 옮긴다. 구역·길·건물 자리(`Buildings`)·적 배치는 옮기지 않는다.

## 5. 지금 한계 (개발 요청으로 따로 처리)

- **대역 그림:** 황건적 졸병 외 사냥개 = 늑대, 관해 = 거대 햇맨, 장각 = 악마 주술사. 장비·관우 합류 자리에는 base 원작 영웅 그림이 선다. 다리 복구 자리는 원작 "정화 마법진" 그림이다.
- **맵 메이커 실행 모드에서는 건물 버튼(구출·합류·복구)을 누를 수 없다.** 안개도 걷히지 않는다. 배치 확인용이다. 그래서 `prevBuilding`으로 숨겨진 장비·관우·훈련소·소굴 입구 자리는 메이커에서 보이지 않는다(조감도에는 표시).
- 고정 배치 적(`maker.units`)은 메이커 전용이다. 실제 게임에서는 스포너로 옮겨야 한다. 파밍 구역은 이미 스포너(`Spawners`)다.
- 기획 미구현: 주민 호송·마을 도착 판정(지금은 구출 즉시 다음 단계), 대화 연출, 관해 격파로 안개 2 해제(지금은 다리 복구 뒤 버튼).
