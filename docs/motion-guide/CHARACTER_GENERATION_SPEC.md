# 새 장수 원화 생성 조건과 공통 모션 규격

2026-10-26 사용자 요청. **원화 생성 단계부터 머리·몸통·다리의 width/height와 연결점을 지정**하여 기존 이동·숨쉬기와 호환되게 만든다. 비율만 맞춘다고 모션이 자동으로 맞는 것은 아니다. 관절 위치·복식 겹침·무기 파지·레이어 구조까지 함께 맞춘다.

## 1. 기준 이미지와 좌표

기준은 프로젝트 루트 각 장수의 original/original.png 및 승인 run PNG다. 400×440 투명 셀, 좌상단(0,0), x→오른쪽, y→아래. 실제 캐릭터 크기는 무기·모자 장식·효과를 모두 포함한 전체 bbox로 비교하지 않는다. 긴 무기 때문에 머리와 다리가 작아지는 오류를 피한다.

새 장수의 이름, 얼굴/수염/모자, 주색/보조색, 신발, 무기, 정지 파지, 이동 파지를 먼저 명시한다. 검토 이미지에는 원화와 기준 장수를 같은 셀·같은 표시 배율로 나란히 놓는다.

## 2. 외형 측정 기준 — 승인 원화의 수동 가이드 박스

아래는 **현재 정지 원화를 눈으로 구획한 대략적인 작업 박스**다. 자동 분할한 정확한 신체 실루엣이나 원작 게임의 공식 비율이 아니다. 윤곽·장식에 따라 몇 px 차이가 난다. 머리는 모자·머리카락·수염을 포함하고, 몸통 박스에는 도포와 어깨가 들어간다. 수염과 몸통이 겹치므로 각 높이를 더해서 전신 높이로 계산하지 않는다. 팔·검 때문에 몸통 폭을 재지 않는다.

| 장수 | 머리 박스 x,y,w,h | 몸통/도포 박스 x,y,w,h | 도포 아래 하체 박스 x,y,w,h |
|---|---|---|---|
| 유비 | 142,94,126,160 | 132,244,124,100 | 146,343,116,57 |
| 관우 | 90,104,142,192 | 78,244,168,104 | 111,343,130,57 |
| 장비 | 106,93,150,192 | 94,249,170,98 | 137,345,137,55 |

관우·장비의 머리 박스가 긴 이유에는 긴 수염이 포함된다. 긴 수염 없는 새 장수 얼굴을192px로 늘리라는 뜻이 아니다. 유비형 작은 체격은 유비 박스, 두꺼운 갑옷/큰 체격은 관우·장비 박스를 출발점으로 삼는다. 머리/몸통 형태와 장식은 장수 고유 디자인을 유지한다.

### 새 장수 생성 시 지정할 치수

- 셀 width=400, height=440. 카메라 우하향3/4, 같은 축척. 무기를 제외한 캐릭터 상단은 대략 y=90~110, 발바닥은 y≈400.
- 머리 width 약126~150px. 머리 height는 모자·수염 포함 약160~192px 범위에서 해당 기준 장수를 따른다.
- 몸통/도포 width 약124~170px, height 약98~104px. 작은 체격과 큰 체격을 구분한다. 기준 장수와의 비교를 우선한다.
- 보이는 하체 전체 width 약116~137px, height 약55~57px(정지 자세 기준). 짧고 넓은 형태이며, 긴 종아리나 가는 막대형 다리를 생성하지 않는다.
- 다리를 드러내려고 도포를 길게 양갈래로 찢지 않는다. 치마처럼 이어지는 밑단으로 골반을 덮는다. 도포 아래의 다리 노출량을 기준 컷과 맞춘다.
- 이 범위는 초안 제약이다. 생성 결과가 숫자를 정확히 지킨다고 간주하지 말고 같은 크기 비교와 관절 배치로 검증한다. 최종 확정 후 실제 박스와 예외값을 새 장수 README에 기록한다.

## 3. 모션에서 실제 고정되는 정확한 수치

외형 박스와 달리 아래는 승인 렌더러의 값이다. 재현 시 코드를 기준으로 한다.

| 항목 | 값 |
|---|---|
| 이동 셀 | 400×440 |
| 몸통 배치 기준 | x=200, 도포 밑단 y=340+상하 변위 |
| R 골반 | (222,315+상하 변위) |
| L 골반 | (178,330+상하 변위) |
| 장비 골반 예외 | 공통 좌표에(-2,-2) |
| 허벅지 모델 길이 | 32 |
| 종아리 모델 길이 | 28 |
| 허벅지 부품 width×height | 64×58, 앵커(32,17) |
| 종아리/신발 부품 width×height | 74×56, 앵커(32,16) |
| 하체 외곽선 | 약3.5px, #0c0d0d |
| 이동 위상 | L=f, R=(f+3)%6 |
| 이동 상하 변위 | 0,-3,-7,0,-3,-7px |
| 숨쉬기 | 0,-2,-4,-2px, 각300ms |

부품 캔버스 width/height는 실루엣 전체 폭이나 두 다리 합산 폭이 아니다. 겹쳐지고 회전한 뒤 화면에서 보이는 크기가 달라진다. 유비 다리를 작아 보이게 만들려 다시 가늘게 줄이지 않는다. 사용자가 원래 굵기로 복구한 결정이 최종 기준이다.

## 4. 연결·레이어·무기

이동 재현은 먼 다리 → 가까운 다리 → 상체 순서다. 도포가 골반을 덮고 허벅지가 신발 연결부를 덮는다. 회전해도 틈이 남지 않을 만큼 겹침을 둔다. 상체·무기는 이동 중 한 덩어리로 유지한다.

공격에서는 상체 전체를 고정할 수 없으므로 팔과 무기의 새 자세가 필요하다. 재생성 편의를 위해 가능하면 몸통, 앞/뒤팔, 손, 무기, 앞/뒤다리, 효과를 분리해 준비한다. **현재 유비·관우 공격은 생성 시트이며 분리 리그 파일은 없다.** 없는 레이어가 있다고 가정하지 않는다.

무기는 길이와 칼날 방향을 지정한다. 관우는 큰 칼날, 곧은 자루, 날카로운 매끈한 면은 몸 바깥쪽/공격 진행 방향, 홈 있는 칼등은 반대쪽이다. 세운 준비 자세에서는 매끈한 면이 화면 오른쪽을 향하는 수정 요청을 따른다. 자루를 손 사이에서 휘게 만들지 않는다. 붉은 얼굴을 가진 관우의 손도 붉다.

무기·효과가 셀을 넘으면 몸을 줄이지 말고 셀 여백을 확장한다. 관우 공격은640×600, 발 기준점(320,520), 기존400×440 대비(+120,+120)이다. 셀 크기가 달라도 같은 월드 기준점에 놓는다.

## 5. 원화 생성 요청문 템플릿

아래 대괄호를 실제 장수 값으로 채우고 승인 PNG를 시각 참조로 전달한다. 텍스트만으로 생성하지 않는다.

> 프로젝트의 승인된 [유비형/관우·장비형] 비율을 유지하는 [장수명] 게임 스프라이트. 우하향3/4, 투명400×440 셀, 큰 머리와 짧고 통통한 하체. 머리 작업박스 [x,y,w,h], 몸통/도포 [x,y,w,h], 보이는 하체 [x,y,w,h]. 발바닥 y≈400, 도포 밑단 y≈340. 기준 이미지와 같은 축척, 굵은 검은 윤곽선과 단순 명암. [얼굴·수염·모자·옷색·신발색·장식]은 고유하게 유지. [무기 종류/길이/날 방향/정지 파지]. 도포는 연결된 치마형 밑단, 허벅지가 도포 아래 자연스럽게 연결되고 짧은 다리 전체가 움직일 여유 확보. 무기 때문에 캐릭터를 축소하지 말 것. 글자·배경·그림자·임의 이펙트 없음. 기존 장수의 신발색이나 복식을 복제하지 말 것.

## 6. 새 장수 승인 전 확인

같은400×440 비교에서 머리/몸통/하체가 기준과 맞는지 → 골반과 도포 겹침 → 기존6프레임 위상 적용 → 좌우 다리 교대 → 숨쉬기 고정부 설정 → 무기 방향/파지 → 정상·느린GIF 순서로 확인한다. 외형만 승인됐다고 새 모션까지 승인 처리하지 않는다.
