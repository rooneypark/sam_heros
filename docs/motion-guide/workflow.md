# 다음 장수 제작과 검수

## 작업 시작

1. 루트 README와 AGENTS, 디자인 가이드, 이 폴더 README를 읽는다. 승인 원화와 최종 이동18프레임, GIF를 직접 연다.
2. 사용자가 지정한 장수·동작 종류·방향을 확인한다. 이동 요청이면 여기의 우하향6프레임이 기본이다. 공격·스킬 요청이면 별도 준비/타격/복귀 근거가 필요하다.
3. 새 장수의 얼굴, 모자, 수염, 복식, 손 피부색, 신발색, 무기 길이/날 크기, 장식 위치를 원화로 확인한다. 없는 외형을 최종 승인으로 취급하지 않는다.
4. 새 영어 폴더에서 작업한다. 기존 세 장수와 공용 렌더러를 무심코 덮어쓰지 않는다. 현재 렌더러를 실행하면 최종 세 폴더가 재출력되므로 단순 참고 작업에서는 실행하지 않는다.

## 구현 순서

1. 상체+팔+무기를 한 덩어리로 준비한다. 매 프레임 새 이미지 생성을 시키지 않는다. 현재 방식의 이동에서는 상체가 정해진 상하 이동만 한다.
2. 도포 밑단과 몸통 중앙을 표시한다. 원화의 비대칭 수염·무기 외곽을 포함한 전체 이미지 중심을 골반 중심으로 착각하지 않는다.
3. 통통한 허벅지와 신발을 닫힌 곡선으로 만든다. 현재 승인 하체 치수와 선 굵기를 출발점으로 삼고 색과 장식은 새 장수 원화에 맞춘다.
4. 기존 위상·투영·앵커 방식을 적용한다. L/R을 청록/주황 관절로 표시한 6장을 만든다. 다리 위상은3프레임 차이, 몸 전체는 반전하지 않는다.
5. 골반을 도포 아래 충분히 겹친다. 신발/허벅지 연결부가 6개 각도 모두에서 닫히는지 확인한다. 장비의 (-2,-2) 보정은 장비 전용이며 새 장수마다 자동 복사하지 않는다.
6. 같은 크기로 기존 장수 옆에 놓고 상체 대비 다리, 도포 아래 노출, 무기 파지, 중심을 비교한다. 과도하게 벌리거나 무릎을 크게 꺾지 않는다.
7. 정상·느린 GIF와 6프레임 시트로 실제 반복을 확인한다. 사용자가 동작을 확인한 뒤 최종 산출물을 정리한다.

## 필수 검수표

- [ ] 1↔4, 2↔5, 3↔6에서 L/R의 역할이 바뀐다. 같은 다리가 계속 앞에 나오지 않는다.
- [ ] 6→1에서 위치·채움·윤곽·속도가 튀지 않는다. 마지막 프레임 중복 정지가 없다.
- [ ] 허리 아래 전체가 움직인다. 길이를 늘린 종아리나 가는 막대형 다리가 아니다.
- [ ] 머리·몸통·무기 외형이 프레임마다 변하지 않는다. 몸의 상하 진폭은 과하지 않다.
- [ ] 골반이 도포에서 떨어져 보이지 않는다. 몸통 중심 대비 두 다리가 앞/뒤로 치우치지 않는다.
- [ ] 무릎, 신발 윗부분, 발뒤꿈치, 다리 사이에 하얀 구멍·배경색 패치·고립된 점·날카로운 잔선이 없다.
- [ ] 밝은 배경과 어두운 배경, 실제 크기와 2배 이상 확대에서 확인했다. 확대만 보고 선을 과도하게 두껍게 만들지 않는다.
- [ ] 상체와 하체 선의 굵기와 색이 일관된다. 수정한 부분의 색 면도 닫혀 있다.
- [ ] 곧은 자루가 손 사이에서도 일직선이다. 손이 자루에서 떨어지지 않는다.
- [ ] 기본자세의 한손/이동의 양손 파지를 구분했다. 신발과 바지색을 다른 장수 색으로 통일하지 않았다.
- [ ] 투명PNG 셀400×440,6장, 일정 기준점; 가로시트2400×440; GIF 순서·100ms·무한루프 확인.
- [ ] 새 결과는 승인 전 후보라고 표시했고 기존 승인본 파일은 변경하지 않았다.

## 실패에서 남긴 규칙

| 이전 문제 | 원인/교훈 | 다음 작업 방식 |
|---|---|---|
| 6장 모두 같은 다리 전방 | 이미지 시트 생성만으로 위상 통제가 안 됨 | 좌표와 L/R 색으로 먼저 검증 |
| 다리가 길고 졸라맨처럼 보임 | 사람 포즈의 길이/관절 표현을 그대로 적용 | 짧은 모델 길이와 넓은 닫힌 실루엣 |
| 골반·무릎이 분리돼 보임 | 잘라낸 조각 회전 시 이음새 노출 | 겹침과 합성 순서, 닫힌 곡선 하체 |
| 지운 곳이 희거나 빈 구멍 | 잔선을 제거하고 면/윤곽 복원을 안 함 | 채움 색+외곽선을 한꺼번에 복원 |
| 관우 자루가 휨 | 부분별 생성/변형의 불일치 | 상체·손·무기 강체 유지 |
| 유비 다리가 너무 얇음 | 작은 몸통에 맞춰 과도하게 폭 축소 | 사용자 복구 결정: 현재 원래 폭 유지 |
| 장비 다리가 앞에 쏠림 | 같은 골반 좌표가 원화 중심에 안 맞음 | 현재 장비만 (-2,-2) 후방 조정 |
| 세 명이 복제 캐릭터처럼 보임 | 비율 통일을 색/복식 통일로 확대 | 움직임 공통, 외형 고유성 유지 |
| 관우·장비 idle까지 양손 | 달리기 리그로 정지 자세도 생성 | 별도 한손 지면지지 원화 사용 |

실패 이미지는 사용자 요청으로 삭제했다. 이 표를 이유로 되살리지 않는다. 현재 최종 파일이 재현의 기준이다.

## 세션을 마칠 때

변경한 값과 이유, 승인 여부, 남은 문제를 새 장수 README에 적는다. 최종 원화·필수 제작 소스·6프레임·GIF·메타데이터만 정리한다. 사용자가 승인하기 전에는 이 공통 가이드의 승인 기준을 교체하지 않는다. 공격/스킬을 새로 만들었다고 이동 기준까지 자동 변경하지 않는다.
