## 규격 및 외형
350×350 투명 RGBA, 왼쪽 아래 시선, PPU100, pivot(0.5,0.3), 접지 기준(175,245). 회색/아이보리 털, 노란 목수건, 큰 머리와 짧은 네 다리. 외형과 크기는 최종 original/original.png를 직접 열어 참고한다. 이동 기준으로 원화·숨쉬기·공격을 공통0.93배 축소한 상태까지 승인했다. 이 축소를 다시 적용하지 않는다. 모든 상태에 동일한 게임 배율을 사용한다.

## 네발 달리기
1. 앞발 지지 마무리, 뒷발 몸 아래 모음.
2. 뒷발로 밀어내며 앞발 접기.
3. 이륙하며 뒷발 뒤로 뻗기.
4. 공중에서 앞발 앞으로 뻗기.
5. 앞발 착지, 뒷발 몸 아래로 회수.
6. 앞발 지지 이동과 뒷발 모으기,1번으로 연결.
실제 포즈는 최종 run/frame-01~06.png와 GIF가 우선한다. 파츠 절단·리그로 교체하지 않고 몸 전체가 이어진 그림을 사용한다. 가까운/먼 다리의 정체성·발 크기·관절 연결을 유지한다. 발끝 흔들림, 프레임별 발 형태 교체, 신체 늘이기, 임의 bbox 정규화를 피한다. 제자리 루트 고정, 의도한 공중 높이는 유지한다.
