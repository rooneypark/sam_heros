# 신규 캐릭터·모션 제작과 검수 보강

2026-10-27 최종 작업 반영. 이 문서는 장수·주민·몬스터에 공통 적용한다. 특정 캐릭터의 복장과 체형을 다른 캐릭터에 그대로 복제하는 규칙은 아니다.

## 기준과 승인 상태

- 최신 사용자 지시 → 해당 캐릭터 최종 PNG와 승인 기록 → 현재 제작 기준 → 과거 문서 순으로 적용한다.
- 기본 규격: 350×350 RGBA 투명 PNG, 왼쪽/왼쪽 아래 대각 시선, PPU100, pivot(0.5,0.3), 발 기준(175,245). 관우의 별도 승인된 공격 피벗 예외는 해당 명세를 따른다.
- 원화 승인, 동작 승인, 위치 보정 승인, 전체 최종 승인을 구분한다. “동작은 좋다, 위치만 수정”이면 자세·크기·시간을 재생성하지 않는다.
- [1장 최종본](../../chapter-1/README.md), [승인 체크섬](../../chapter-1/FINAL_MANIFEST.json), [재생 화면](../../chapter-1/index.html)이 이번 사례의 기준이다. DELETE_ME 안의 시안·생성기는 제작 기준이 아니다.
- 승인된 기존 유비·관우·장비·조운 및 1장 캐릭터는 변경 요청이 없는 한 보호한다.

## 원화에서 먼저 정할 값

다음 항목을 원화와 함께 기록한다. 보편적인 고정 비율을 추측하지 말고 승인 그림에서 측정한다.

| 항목 | 기록 내용 |
| --- | --- |
| 머리 | 모자 포함/제외를 구분한 width, height와 중심 |
| 몸통 | 어깨·가슴·허리 폭, 어깨에서 골반까지 높이 |
| 하체 | 허벅지와 신발 각각 width/height, 원화에서 보이는 길이 |
| 연결 | 좌우 골반 위치, 몸통 중심, 밑단 곡선, 다리 겹침 깊이 |
| 자세 | 두 발 간격, 각 발 접지점, 발끝 방향, 지지 중심 |
| 무기 | 손잡이 축, 총길이, 칼날 길이·폭, 파지점 |
| 캔버스 | 공통 축척, root/pivot, 모든 동작에 필요한 여백 |

신체 크기 측정에 무기·모자 장식·이펙트 전체 bbox를 사용하지 않는다. 얼굴 자동 검출은 맨팔을 얼굴로 오인할 수 있으므로 검출 영역을 그림 위에 표시해 확인한다.

## 옷과 체형을 단순화하는 방법

- 주름 최소화는 디테일 삭제가 아니다. 겹깃·허리끈·매듭·소매끝·밑단 구분과 소수의 필요한 주름, 제한된 색면 음영을 남긴다.
- 허리 아래 옷자락이 과도한 부채꼴이면 작은 상체에 비해 하체가 가려지고 이동 실루엣이 어색해진다. 필요할 때 밑단 폭·벌어짐·면적을 줄여 몸에 가깝게 정리한다. 모든 캐릭터의 도포를 일괄 변경하지 않는다.
- “민소매”를 맨몸으로, “헐렁하게”를 지나치게 긴 옷으로, “근육을 조금”을 거대한 근육질로 해석하지 않는다. 요청한 부위와 변화량을 좁혀 수정한다.
- 최종 졸병·관해는 좁은 짧은 밑단과 모은 발이 기준이다. 관해는 약한 상체 근육 볼륨이며 과거 큰 근육질/너무 마른 시안은 제외한다.

## 이동 6프레임

1. 승인 원화의 상체 크기와 중심을 먼저 고정한다.
2. 하체의 굵기, 관절 길이, 골반 간격을 각각 설정한다. 다른 장수의 다리 배율 하나를 복사하면 상체 대비 비율이 맞지 않을 수 있다.
3. 짧은 다리를 길게 늘려 보폭을 만들지 않는다. 허벅지 회전과 앞뒤 겹침으로 표현하고, 좌우 위상은 3프레임 차이로 둔다.
4. 다리를 중앙으로 과하게 몰거나 바깥으로 크게 벌리지 않는다. 기본자세와 이동의 골반 중심이 연결되는지 확인한다.
5. 옷자락 아래 연결부는 충분히 겹치고, 허리끈 끝은 앞에 남긴다. 원래 정지 다리의 잔상이 함께 남지 않게 한다.
6. 원화→이동1, 1↔4·2↔5·3↔6의 좌우 교대, 6→1을 정상 속도와 느린 속도로 확인한다. 단순 관절 점이나 정지 시트만 보고 완료하지 않는다.

## 공격·스킬의 크기와 위치

- 공격·스킬은 7~8프레임. 준비→타격→복귀와 이펙트 시점을 구분한다. 1장 현재 승인본은 각8프레임이다.
- 머리·몸통·다리와 무기의 로컬 길이·굵기를 유지한다. 회전에 따른 투영 폭 변화와 실제 성장·축소를 구별한다.
- 생성 프롬프트에 크기 고정을 적었다는 이유로 검증됐다고 판단하지 않는다. 원화와 프레임을 동일한 표시 배율로 나란히 놓고 비교한다.
- 한 시트에 공통 배율을 적용해도 생성된 포즈 자체의 치수 변화가 해결되지는 않는다. 프레임별 bbox 자동맞춤, 몸 전체 확대축소, 모핑으로 감추지 않는다.
- 발 기준 정렬은 **두 신발의 접지 중심과 지면 높이**를 사용한다. 검·잔상·부적이 커지는 방향을 포함한 이미지 중심으로 정렬하지 않는다. 색상 기반 자동 검출 결과는 손·바지·이펙트 오검출 여부를 확인한다.
- 제자리 공격은 root 이동이 없어야 한다. 몸을 숙이거나 무게를 옮기는 동작은 허용하되 장면 전체가 갑자기 옆으로 밀리는 현상은 교정한다.
- 위치만 문제라면 기존 프레임 전체를 정수 픽셀 평행이동한다. 재생성·확대축소·타이밍 변경을 하지 않는다. 이동량과 전후 앵커를 기록한다.
- 이동 뒤 무기·효과가 캔버스 밖으로 잘리는지도 확인한다. 잘림을 피하려고 캐릭터를 축소하지 않는다. 캐릭터/무기의 실체가 잘리면 고정 셀 안에서 해결할 별도 수정이 필요하다.
- 실제 복귀 동작은 유지한다. 움직임 없이 정지 자세의 모양만 바뀌는 끝 프레임은 동일한 승인 원화를 재사용해 깜박임을 없앤다.

이번 위치 보정 사례: 일반공격5번이 졸병은 오른쪽31px, 관해는34px 치우쳤다. 해당 프레임을 왼쪽으로 이동하고 지면 높이를 맞췄다. 이 값은 해당 캐릭터 전용이며 새 장수에 복사하지 않는다. 관해의 고정 셀 경계에 닿는 극미세 잔상 가장자리(알파30미만)가 잘린 것은 이번 승인 결과의 개별 사항이며 일반적인 허용 기준이 아니다.

## 숨쉬기·무기·색상

- 숨쉬기는 4프레임, 상하 한 주기. 하반신은 고정하고, 땅에 짚은 무기와 그 주먹은 고정한다. 상체 이동량과 연결 구간을 기록한다.
- 긴 무기는 손 사이에서도 단일 직선 축을 유지한다. 앞뒤 레이어와 손가락 파지를 확인한다. 무기 회전과 무기 자체 변형을 혼동하지 않는다.
- 잔상은 마지막 레이어에 합성하고 복귀 중 의도치 않은 재타격 효과가 생기지 않게 한다.
- GIF는 모션 전체 공통 팔레트를 사용한다. PNG는 같은데 GIF만 색이 바뀌면 팔레트·투명도·disposal을 먼저 점검한다.

## 최종 검수와 보관

- [ ] 원화와 모든 프레임의 표시 배율·카메라 방향 일치
- [ ] 실제 크기와 확대에서 몸·무기·옷자락·파지·잔선·흰 구멍 확인
- [ ] 밝고 어두운 배경에서 투명 외곽과 효과 확인
- [ ] 일반속도·느린 반복 및 상태 전환에서 순간이동·색 변화·끝 연결 확인
- [ ] 위치 교정은 전후 픽셀 비교로 평행이동 외 변화가 없는지 확인
- [ ] 350×350 RGBA, 프레임 수·시간·순서·pivot·방향 메타데이터 검사
- [ ] 다른 승인 캐릭터의 체크섬 유지 확인
- [ ] 사용자 승인 후 status와 최종 PNG SHA256 기록

최종 폴더에는 original, 개별 PNG, 시트, GIF, animation.json, 원본 참조와 승인 명세를 둔다. 이전 시안과 자동 생성기는 DELETE_ME로 분리한다. 문서·미리보기·파일 묶음도 최종본을 가리키도록 갱신한다. 최종 재현은 승인 frame PNG와 animation.json을 기준으로 하며, 원본 생성 시트를 다시 잘라 최종 위치 교정을 잃지 않는다.

검수 보고에는 실제 확인한 범위를 적는다. 파일 규격 검사 통과를 신체·무기 치수의 완전한 불변성 증명으로 표현하지 않는다.
