# 게임 조작 UI 개발 인계

현재 리소스: [삼국 UI 테마](../art/ui/themes/samguk/README.md).
시안7종·화면별 CSS·manifest·검수결과·비교 이미지가 같은 폴더에 있다.

- 진입 CSS: `art/ui/themes/samguk/theme.css`
- 시안 보드: `art/ui/themes/samguk/index.html`
- 실행 검토: `web/ui-proposal.html`
- 테스트: `tools/test_ui_theme.cjs`
- 기존 HUD/EXP 시안은 `art/ui/source/`에 보존.
- 실제 게임 전역에는 새 패널 테마를 아직 적용하지 않음. 개발자가 가이드에 따라 연결.
- 환경설정 Canvas는 이번 새 테마 범위 외.

Git 업로드: 위 패키지와 이 문서를 포함하고 DELETE_ME/ui-theme-intermediate는 제외한다. 저장소의 기존 다른 변경은 이번 정리로 되돌리지 않았다. 커밋/푸시는 사용자 진행.
