# 시설 작업 애니메이션 검토본

승인 시안 integrated-animation-concept-v2 기반. imagegen으로 시설별 6프레임 생성 후 얼굴 기준 정수 이동 정렬. 첫 프레임을 고정 바탕으로 두고 작업 마스크 안만 합성. 공통 GIF 팔레트. 512×512 불투명 배경 검토 PNG이며 게임용 투명 납품·맵 등록 전 단계. 마지막 프레임은 처음과 동일. 기존 지형/NPC 실행 자산은 변경하지 않음.

주막: 국자 젓기. 대장간: 붉은 두건 대장장이 망치질. 훈련소: 은발 푸른 도복 교관 목인 타격.

source-sheet.png는 생성 원본, work-area-mask.png는 움직임 허용 영역. qa.json의 고정 픽셀 검사는 마스크 바깥만 보장하며 작업 영역 안 형태 일관성은 시각 검수 대상.
