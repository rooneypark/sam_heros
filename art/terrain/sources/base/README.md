# 황건소탕 환경 자산

현재 사용자 검토용 공용 자산. 상세 제작 규칙·파일 역할·생성 프롬프트 요약·검수는 [전체 재작화 가이드](../../../../maps/maps/chapter-1/review/characters/docs/REDRAW.md)에 기록했다.

sources/에는 내장 image_gen으로 생성한 원본 시트4장을 보존한다. 개별PNG36장과 재질PNG3장은 실제 맵메이커에서 사용한다. 등록은 content/samguk/tiles.json이며 36개 오브젝트와4개 지형 브러시로 구성된다.

지형 재질은 Canvas의 격자 투영/클리핑을 거쳐 런타임 텍스처로 등록된다. 경로와 물 경계가 이웃에 맞게 연결되므로 완성된 배경 이미지 한 장을 바닥에 깐 방식이 아니다. 지형 색이나 오브젝트를 수정하면 해당 PNG만 교체할 수 있다.

모든 신규 자산 ID는 sg2_로 시작한다. 표준건물 PPU100, 바닥·산 PPU120. 기존 원작/이전 sg_ 이미지를 다시 섞지 않는다. 최종 승인 전이며 차기 작업의 승인 기준으로 승격하지 않는다.
