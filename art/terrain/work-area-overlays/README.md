# 고정 배경 + 작업 구역 오버레이

사용자가 보라색으로 표시한 작업 영역을 통째로 투명 레이어로 제작하는 방식. 현재 검토본이며 맵 등록 전.

- background.png: 작업대를 제거한 고정 배경. 훈련소 목인은 배경에 포함.
- work-01~06.png: 주모+조리대+냄비, 대장장이+모루, 교관+목검의 전체 작업 구역. RGBA512×512.
- frame-01~06.png: 같은 크기의 배경과 작업 레이어를 알파 합성한 결과.
- sources/: 내장 imagegen 생성 원본. 승인 integrated-animation-concept-v2 참조. 투명 작업 시트는 집·지붕·지면을 포함하지 않게 생성. 배경에서는 중복 조리대·모루를 제거.
- animation.json: 공통 배율, 전체 작업 구역 정수 정렬, 6프레임 시간과 배경 픽셀 검사 기록. 프레임별 확대축소 없음. 조리대/모루 받침/교관 하체는 첫 프레임의 같은 영역으로 고정. 팔 가장자리에 맞춰 배경을 잘라 붙이지 않음.
- all-facilities.gif / layers-overview.png: 세 시설 동시 재생 및 레이어 구성 비교.

생성 방식: built-in imagegen. 핵심 프롬프트: 승인 화풍 유지, 전체 작업 구역 6프레임, 실제 투명 배경, 집/지면 제외, 같은 크기·색·시점, 팔·작업 도구만 동작. 재현 tools/package_work_area_overlays.py.

## 후속 수정
대장간 사용자 패스: 기존 파일 해시 전부 유지. 주막 식탁 상판·양쪽 기둥까지 고정 마스크 확대. 훈련소 하체 수평 덮기 제거: 내려오는 검끝을 삭제하지 않고 전체 작업 프레임 유지. 마지막은 첫 준비 자세와 동일. correction-qa.json 검사 기록.
