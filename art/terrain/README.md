# 공용 지형

지형별 폴더에 실행 PNG를 둡니다. tree는 나무, tavern은 주막, blacksmith는 대장간입니다. grass-material / earth-material / water-material은 연결형 지면 재질입니다.

[등록 JSON](../../content/samguk/tiles.json)이 ID·크기·피벗·충돌·레이어의 단일 기준입니다. 생성 시트·제작 근거는 sources에 보존합니다. 개별 맵에 그림을 복제하지 않고 같은 등록 ID를 참조합니다.
