# 황건소탕 공용 맵 부품

2026-10-28 제작, 사용자 검토용. 최종 승인 캐릭터의 굵은 외곽선·작은 비율에 맞춘 투명 PNG 12종이다. 이미지 생성 원본은 sources/buildings.png, sources/props.png에 보존한다. 단순 잘라내기와 동일축 축소만 적용했다.

등록: content/samguk/tiles.json. 맵메이커의 **삼국** 팔레트에서 다른 맵에도 배치할 수 있다. 지형은 기존 원작 엔진 자산을 재사용한다. 흙길 12조각, 흙마당 13조각은 sourceTile 별칭으로 원래 자동 연결 규칙을 보존한다.

공통 ppu=100, pivot=[0.5,0.18], decoData. 캐릭터의 350×350 캔버스 규격을 건물에 적용하지 않는다. 원근·빛은 좌상단, 건물은 위에서 보는 사선 시점. 지붕에는 최소한의 짚/기와 구분을 남기고 사실적인 재질 노이즈는 피한다.

등록 ID는 sg_ + 영문 이름(하이픈은 밑줄)이다. 건물은 시각 자산 및 충돌만 제공한다. 주막 영업, 제작, 감옥 개폐 같은 신규 기능은 추가하지 않았다. 기존 시나리오 인터랙션은 그대로 유지한다.

재포장 스크립트: tools/map-art/package_chapter1.py. **이 스크립트는 보존된 배치 시안에서 작업 맵을 다시 만든다. 사용자가 맵을 편집한 뒤에는 재실행하지 않는다.** 이미지 수정만 필요하면 패키징 부분만 별도로 실행한다.
