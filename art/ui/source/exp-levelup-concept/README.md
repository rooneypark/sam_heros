# EXP 획득·레벨업 움직이는 시안

index.html을 로컬 서버로 열어 검토한다. 기존 플레이 캡처 위에 코드로 UI를 그리는 별도 연출 시안이며 실제 전투/저장/밸런스는 변경하지 않는다. game runtime에는 미적용.

- 조이스틱은 원본 캡처 그대로 유지. 새 조이스틱 그림을 사용하지 않음.
- 머리 위 기존 소형 HP/EXP 위치와 원래 색상 의미 유지. 화면 오른쪽 확대는 검수용.
- 3개 입자가 장수로 이동, 마지막 입자 도착 후 EXP 획득, 게이지 충전, LEVEL UP!, 잔여 EXP 이월.
- 일시정지·처음부터·0.5배속·시간 슬라이더 지원. 6.5초 반복.
- Lv3→4, 88%→만충→잔여12%는 시각 확인용 예시이며 계산된 밸런스 값이 아님.
- 실게임의 경험치 수령 시점/자동 레벨업/능력치/효과음은 보존. 시안에는 오디오 없음.

UI는 기존 HTML/CSS/Canvas 방식으로 제작했다. 소스 캡처: docs/ui-review-2026-10-28/11-controls.png. 시안 승인 후 엔진의 월드 좌표 투영에 연결해야 하며 현재 캡처 픽셀 좌표를 실제 게임 위치값으로 사용하면 안 된다.

## 사용자 확인
EXP 입자 → 게이지 충전 → 레벨업 연출 시안은 사용자 확인 완료, 보존한다. 기존 조이스틱 유지. 실제 게임 적용은 별도 작업이다.
