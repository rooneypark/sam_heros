# 플레이 HUD 시안

사용자 요청: 삼국히어로즈 화풍에 맞춰 플레이 HUD·조이스틱·HP바의 외형만 재디자인. 기존 기능·위치 유지. 승인 전 시안이며 실행 CSS/PNG/manifest는 교체하지 않는다.

참조: docs/ui-review-2026-10-28/11-controls.png, 08-boss.png, characters/liu-bei/original/original.png. 가이드의 과거 원작/승인 목업 이미지 파일은 현재 저장소에서 누락되어 참조하지 못했다.

고정 기준:
- 목표 패널 left2.5%, top5.5%; 자원 패널 right2.5%, top5.5%.
- 보스 패널 left/right15%, top13.5%.
- 조이스틱 기존 터치 중심·반경128, 손잡이 반경64, alpha0.40392157 유지. 시안의 조작 위치는 참조 캡처의 입력 상태.
- HP 너비0.375/높이0.06, EXP 높이0.05/간격0.012. 빨강HP·청록실드·금색EXP 의미 유지.
- 새 기능/버튼/미니맵/장수 초상화 도크 추가하지 않는다.

표현: 굵은 먹색 외곽선, 평면2단 명암, 억제된 황토색 테두리, 아이보리 글자, 반투명 옥색 조이스틱. 복잡한 금속/용 장식 배제.

생성 시안은 배치 의도를 보여주는 래스터 목업이다. 승인 후 실제 CSS와 PNG에 적용할 때 기존 수치·좌표로 정확하게 구현하며 생성된 글자/좌표를 실행값으로 추출하지 않는다.
