# 오전 폐기 후 새 작업 — 검토본

최신 요청: [재개 명세](../docs/motion-guide/RESTART_2026-10-28.md). 오전 폐기 자료는 참조하지 않았다. 승인 원본 207개 PNG의 체크섬을 보존했다. 기존 장수 폴더와 게임 등록 데이터는 변경하지 않았다.

## 결과와 한계

- 장비·관우 기본공격/스킬1/스킬2: 각8프레임 새 재작화 **검토본**. 원본·숨쉬기를 외형 참조로, 이전 승인 스킬2를 새 스킬1 동작 참조로 사용했다.
- 장비 기본공격은 두 차례 시트와 별도 타격 자세까지 시도했지만 준비→타격 사이 손 간격/무기 치수가 완전히 일정하지 않다. **파지점 고정 조건 미달, 최종 사용 불가.** 반복 생성 요청문으로 치수 불변성을 보장할 수 없음을 확인했다.
- 관우·장비 나머지 재작화도 기존 원본과 완전히 같은 선·로컬 치수가 검증된 결과가 아니다. 원본 교체나 승인 처리하지 않는다. 별도 원화 전체 재작화는 시행하지 않았다.
- 유비 스킬1/2: 기존 캐릭터 PNG와 프레임 시간을 그대로 보존한 별도 단일/전체 치유 효과. body PNG는 기존 PNG와 픽셀 동일. 효과는 별도 fx PNG로 저장했다.
- 관우 이동6프레임: 생성 시도는 원본 픽셀을 보존하지 못해 채택하지 않았다. 사용자 요청대로 기존 은색 칼날만 자루 축에 대해 기하 반전했다. 칼날 영역 밖 픽셀 변경0, 몸/손/자루/다리/시간 유지.

## 확인

- index.html: 9종 비교, 원본 겹침, 기본→동작→기본, 정지/프레임 이동/느린 재생. 실제 미리보기 프레임별 타이밍 적용.
- all-frames.png: 전체70프레임.
- 각 모션:350×350 투명PNG, spritesheet, frames-overview, 공통 팔레트 GIF, 느린GIF, animation.json.
- 자동 브라우저 열기는 file URL 보안 정책으로 차단되어 **실제 브라우저 재생 검수는 미완료**다. 정지 시트 시각 검토, GIF 디코딩/타이밍, 원본 보호, 유비 body 동일성, 이동 보호영역 검사를 수행했다. 반복 재생을 직접 보았다고 주장하지 않는다.

## 재현

내장 image_gen 사용. 정확한 요청문과 원시 경로: sources/generation.json 및 sources/additional-generation.json. tools/character-motion/package_restart_20261028.py는 새 폴더만 출력한다. 시트 공통 축척과 정수 접지 정렬은 생성된 신체 치수 불변성을 증명하지 않는다. 폐기 시안은 현재 최종 자산의 대체물이 아니다.
